本节介绍 RouterOS 的自动化与集成接口——API、脚本以及 REST API。当你要构建与 RouterOS 交互的工具、脚本或应用程序时，请使用本节内容。API 和 REST API 允许外部工具通过网络与路由器通信；脚本则运行在路由器本身上。
