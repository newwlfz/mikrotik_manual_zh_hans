## file/copy {#filecopy}
**类型:** 命令

复制文件或目录。目录会递归复制，包括其所有内容。请参阅 [文件](../../system-information-and-utilities/files.md#copy-a-file-or-directory) 指南。

<ArgTable c1="参数" c2="类型" c3="描述">
<ArgTableRow arg="name" typ="file">副本的目标名称。可以包含路径，以便复制到其他目录。</ArgTableRow>
</ArgTable>
