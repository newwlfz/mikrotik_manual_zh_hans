## cmr/upgrade/job/show-devices {#cmrupgradejobshow-devices}
**软件包：** cmr
**类型：** Command

显示所选任务涵盖的设备。计划任务仅在任务启动时才解析其设备列表，因此对于尚未启动的任务，输出可能为空。

<ArgTable c1="标志" c2="名称" c3="描述">
<ArgTableRow arg="L" typ="controller">包含 CMR 服务器本身（自客户端）。</ArgTableRow>
</ArgTable>
