## interface/6to4 {#interface6to4}
**类型：** 目录

[6to4](../../virtual-private-networks/6to4.md) 是一种特殊机制，允许 IPv6 数据包通过 IPv4 网络传输。

<ArgTable c1="标志" c2="名称" c3="描述">
<ArgTableRow arg="X" typ="disabled">项目是否被禁用。</ArgTableRow>
<ArgTableRow arg="R" typ="running">接口是否正在运行。</ArgTableRow>
</ArgTable>

<ArgTable c1="参数" c2="类型" c3="描述">
<ArgTableRow arg="name" typ="string">接口名称。</ArgTableRow>
<ArgTableRow arg="mtu" typ="num">Layer3 最大传输单元。</ArgTableRow>
<ArgTableRow arg="local-address" typ="ipAddr">数据包的源地址，属于路由器本地。</ArgTableRow>
<ArgTableRow arg="remote-address" typ="alt { address: ipAddr
, name: string
 }">6to4 隧道远端的 IP 地址。如果未指定，则 IPv4 地址从 2002::/16 网关地址派生。</ArgTableRow>
<ArgTableRow arg="keepalive" typ="super { keepalive-interval: time [1 .. ]
, [keepalive-retries] [ ,num [1 .. ]]
 }">
keepalive 参数设置时间间隔，在该间隔内，即使隧道远端发生故障，隧道的 running 标志仍会保留。如果配置的时间间隔和重试次数失败，则移除接口的 running 标志。  
参数按以下格式编写：`KeepaliveInterval,KeepaliveRetries`  
 其中 KeepaliveInterval 是时间间隔，KeepaliveRetries 是重试次数。  
默认情况下，keepalive 设置为 10 秒和 10 次重试。
</ArgTableRow>
<ArgTableRow arg="dscp" typ="num">数据包的 DSCP 值。Inherited 表示 DSCP 值从待封装的数据包继承。</ArgTableRow>
<ArgTableRow arg="clamp-tcp-mss" typ="bool">控制是否更改接收到的 TCP SYN 数据包的 MSS 大小。启用后，如果当前 MSS 大小超过隧道接口 MTU（考虑 TCP/IP 开销），路由器会更改接收到的 TCP SYN 数据包的 MSS 大小。接收到的封装数据包仍包含原始 MSS，只有在解封装后才会更改 MSS。</ArgTableRow>
<ArgTableRow arg="dont-fragment" typ="enum (no | inherit)">
是否在相关数据包中包含 DF 位。
- `no` - 如有需要则分片。
- `inherit` - 使用原始数据包的 DF 标志。
</ArgTableRow>
<ArgTableRow arg="ipsec-secret" typ="string" syscap="security">当指定密钥时，路由器会用预共享密钥和策略向 remote-address 添加一个动态 IPsec 对等体（默认情况下 phase2 使用 sha1/aes128cbc）。</ArgTableRow>
</ArgTable>

<ArgTable c1="只读参数" c2="类型" c3="描述">
<ArgTableRow arg="actual-mtu" typ="num">隧道的实际最大传输单元。</ArgTableRow>
<ArgTableRow arg="current-remote-address" typ="ipAddr">远端当前的 IPv4 地址。</ArgTableRow>
</ArgTable>
