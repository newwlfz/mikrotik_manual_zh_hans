## ip/proxy/clear-cache {#ipproxyclear-cache}
**类型：** 命令

删除 Web 代理缓存中的所有对象。更改 [`/ip/proxy`](./index.md) 中的任何设置也会清除缓存。关于缓存的概述，请参阅 [Web 代理](../../../network-management/proxy/web-proxy.md)。
