## system/ntp/client/reset-freq-drift {#systemntpclientreset-freq-drift}
**类型：** 命令

将客户端测得的本地时钟频率漂移重置为零，丢弃客户端此前学到的校正值。随着客户端持续轮询其服务器，该估计值会被重新建立。请参阅 [NTP](../../../../system-information-and-utilities/ntp.md) 指南。
