6to4 是一种特殊机制，允许 IPv6 数据包在未显式配置隧道接口的情况下通过 IPv4 网络传输。它特别适用于通过不支持 IPv6 的网络连接两个或多个 IPv6 网络。6to4 机制以两种模式运行。如果未配置 *remote-address*，且前 16 位是 *2002*，则路由器会封装 IPv6 数据包并直接通过 IPv4 发送，接下来的 32 位会被解释为目标地址（转换为十六进制的 IPv4 地址）。另一种情况下，IPv6 数据包会直接发送到 IPv4 *remote-address*。

## 配置示例 {#configuration-examples}

### 简单 6to4 隧道封装（不工作） {#simple-6to4-tunnel-encapsulation-not-working}

![](/img/01fb25e7c82ced9c.webp)

可以使用 2002::/16 分配的地址空间，简单地通过 IPv4 网络路由 IPv6 数据包。所有 6to4 节点都必须具有可访问的 IPv4 地址——如果你在 Internet 上运行此设置，则所有 IPv4 地址都必须是公网地址。

#### R1 配置 {#r1-configuration}

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个 IPv6 地址，其中前 16 位为 '2002'，接下来的 32 位为十六进制格式的 IPv4。例如，如果路由器的 IP 地址是 10.0.1.1，则 IPv6 地址是 2002:A00:101::

```ros
/ipv6/address
add address=2002:a00:101::/128 advertise=no interface=6to4-tunnel1
```

添加一条通过 6to4-tunnel 接口指向专门分配的 6to4 隧道范围的路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### R2 配置 {#r2-configuration}

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个按照与 R1 相同原则生成的 IPv6 地址。在此例中，10.0.2.1 转换为 2002:A00:201::

```ros
/ipv6/address
add address=2002:a00:201::/128 advertise=no interface=6to4-tunnel1
```

这一侧同样需要 6to4 路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### 测试 {#testing}

配置两台设备后，如果 IPv6 地址生成正确，应该可以 ping 通这些地址。

从 R1：

```ros
/ping 2002:a00:201::
```

### Hurricane Electric Tunnel Broker 示例 {#hurricane-electric-tunnel-broker-example}

本示例展示如何通过 6to4 隧道，经由 IPv4 网络在 RouterOS 设备上获得 IPv6 连接。

要创建隧道，你需要一个公网 IPv4 地址，并启用来自 Tunnel Broker IPv4 服务器的 ping。

当你使用 [Hurricane Electric Tunnel Broker](https://tunnelbroker.net) 创建隧道时，你会收到一个路由的 /64 IPv6 前缀以及设置隧道所需的其他信息。

*![](/img/0c5a58e7258874ec.webp)*

*本示例假设你的公网 IPv4 地址是 194.105.56.170*

Hurricane Electric 在 'Example Configurations' 部分提供了可直接用于 RouterOS 的命令：

```ros
/interface/6to4
add comment="Hurricane Electric IPv6 Tunnel Broker" disabled=no local-address=194.105.56.170 mtu=1280 name=sit1 remote-address=216.66.80.90
/ipv6/route
add comment="" disabled=no distance=1 dst-address=2000::/3 gateway=2001:470:27:37e::1 scope=30 target-scope=10
/ipv6/address
add address=2001:470:27:37e::2/64 advertise=no disabled=no eui-64=no interface=sit1
```

这些命令会设置隧道。随后路由器可以连接到 IPv6 主机，但最终用户设备（计算机、平板电脑、手机）尚不具备 IPv6 连接。

要为客户端分配 IPv6 地址，请将 Routed IPv6 Prefix 添加到内部接口（默认为 bridge-local）。

```ros
/ipv6/address/add address=2001:470:28:37e:: interface=bridge-local advertise=yes
```

通过网络发现启用 DNS 服务器通告。

```ros
/ipv6/nd/set [ find default=yes ] advertise-dns=yes
```

最后添加 IPv6 DNS 服务器（这些是 Google 公共 DNS 服务器，你也可以使用 Hurricane Electric 提供的服务器 - 2001:470:20::2）。

```ros
/ip/dns/set allow-remote-requests=yes servers=2001:4860:4860::8888,2001:4860:4860::8844
```

在你的设备上启用 IPv6 后，使用 [https://test-ipv6.com](https://test-ipv6.com/) 测试 IPv6 连接。
