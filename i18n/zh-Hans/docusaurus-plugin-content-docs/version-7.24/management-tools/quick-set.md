### 概述 {#summary}

**Quickset** 是一个简单的配置向导页面，只需点击几下即可完成路由器配置。当用户在 Web 浏览器中打开默认 IP 地址 192.168.88.1 时，首先看到的就是此页面。

Quickset 适用于所有具有某种出厂默认配置的设备。没有配置的设备必须手动配置。最受欢迎且推荐的模式是 HomeAP（或 HomeAP dual，具体取决于设备）。此 Quickset 模式为家庭用户提供最简单的术语和最常用的选项。

### 模式 {#modes}

根据路由器型号，Quickset 下拉菜单中可能会提供不同的 Quickset 模式：

- **CAP**：受控接入点，一种将由集中式 CAPsMAN 服务器管理的 AP 设备。仅在已设置 CAPsMAN 服务器时使用。
- **CPE**：客户端设备，它将连接到接入点 (AP) 设备。提供扫描所在区域 AP 设备的选项。
- **HomeAP**：大多数家庭用户默认的接入点配置页面。提供更少的选项和简化的术语。
- **HomeAP dual**：双频设备（2GHz/5GHz）。大多数家庭用户默认的接入点配置页面。提供更少的选项和简化的术语。
- **Home Mesh**：用于组建更大的 WiFi 网络。启用路由器中的 CAPsMAN 服务器，并将本地 WiFi 接口置于 CAPsMAN 控制之下。只需在按住复位按钮的情况下启动其他 MikroTik WiFi AP，它们就会加入此 HomeMesh 网络（详情请参阅其快速指南）。
- **PTP Bridge AP**：当需要在同一网络中透明地互连两个远程位置时，将一台设备设置为该模式，并将另一台设备设置为下一个模式（PTP Bridge CPE）。
- **PTP Bridge CPE**：当需要在同一网络中透明地互连两个远程位置时，将一台设备设置为该模式，并将另一台设备设置为上一个模式（PTP Bridge AP）。
- **WISP AP**：与 HomeAP 模式类似，但提供更高级的选项，并使用行业标准术语，例如 SSID 和 WPA。

### HomeAP {#homeap}

如果您想快速配置家庭接入点，应使用该模式。

#### 无线 {#wireless}

在此部分设置您的无线网络：

- **网络名称**：您的智能手机将如何显示您的网络？在此设置任意您喜欢的名称。在 HomeAP dual 中，您可以将 2GHz（传统）和 5GHz（现代）网络设置为相同或不同的名称（见 FAQ）。可使用任意格式的任意名称。
- **频率**：通常可以保留 “Auto”，这样路由器会扫描环境并选择占用最少的信道（该操作只执行一次）。如果需要试验，可使用自定义选择。
- **频段**：通常保留默认值（2GHz b/g/n 和 5GHz A/N/AC）。
- **使用访问列表 (ACL)**：如果您希望根据用户的 MAC（硬件）地址限制谁可以连接到您的 AP，请启用此选项。要使用此选项，首先需要允许这些客户端连接，然后使用下方 “Copy to ACL” 按钮。这会将选中的客户端复制到访问列表。构建访问列表 (ACL) 后，您可以启用此选项，禁止其他任何人尝试连接到您的设备。通常可以保持此选项不变，因为无线密码已提供所需的限制。
- **WiFi 密码**：此处最重要的选项。设置一个安全密码，同时加密您的无线通信；连接无线网络时需要用到该密码。
- **WPS 接受**：使用此按钮可授予支持 WPS 连接模式的特定设备访问权限。适用于打印机和其他难以输入密码的外围设备。首先在客户端设备中启动 WPS 模式，然后在此处单击一次 WPS 按钮以允许该设备。该按钮仅工作几秒钟，并且按客户端逐个操作。
- **访客网络**：适用于无需知道您主 WiFi 密码的家中访客。可在此选项中为他们设置单独的密码。重要！访客用户将无法访问您 LAN 中的其他设备以及其他访客设备。此模式会启用 Bridge 过滤器来阻止此类访问。
- **无线客户端**：此表显示当前连接的客户端设备（其 MAC 地址、是否在您的访问列表中、最后使用的 IP 地址、连接时长、以 dBm 表示的信号强度以及条形图）。

#### 互联网 {#internet}

- **端口**：选择哪个端口连接到 ISP（互联网）调制解调器。通常是 Eth1。
- **地址获取**：选择 ISP 如何向您提供 IP 地址。请向您的服务提供商咨询此选项以及其他选项（IP 地址、子网掩码、网关）。
- **MAC 地址**：通常不应更改，除非您的 ISP 已将您绑定到特定 MAC 地址，并且您已将路由器更换为新路由器。
- **路由器防火墙**：这会为您的路由器和网络启用安全防火墙。请始终确保选中此复选框，以免从互联网端口访问您的设备。
- **MAC 服务器 / MAC Winbox**：允许从 LAN 端口侧以 MAC 地址模式使用 [Winbox 实用工具](https://mt.lv/winbox) 进行连接。当 IP 模式不可用时，可用于调试和恢复。仅供高级用户使用。
- **发现**：允许其他 RouterOS 设备通过型号名称识别此设备。

#### 本地网络 {#local-network}

- **IP 地址**：大多数情况下可保留默认值 192.168.88.1，除非您的路由器位于另一台路由器之后。为避免 IP 冲突，请改为 192.168.89.1 或类似地址。
- **子网掩码**：大多数情况下可保留 255.255.255.0。
- **桥接所有 LAN 端口**：允许您的设备相互通信，例如，即使您的电视通过以太网 LAN 线缆连接，而您的 PC 通过 WiFi 连接。
- **DHCP 服务器**：通常，您会希望家庭网络自动配置 IP 地址，因此请将 DHCP 设置保持为开启并保留默认值。
- **NAT**：仅当您的 ISP 为路由器和本地网络都提供了公网 IP 地址时，才关闭此选项。否则，请保持 NAT 开启。
- **UPnP**：此选项会为受支持的程序和设备（例如您的 NAS 磁盘和点对点实用工具）启用自动端口转发（有些人称之为“向本地网络开放端口”）。请谨慎使用，因为此选项有时会在您不知情的情况下将内部设备暴露到互联网。仅在明确需要时启用。

#### VPN {#vpn}

如果您想从互联网访问本地网络（以及路由器），请使用安全的 VPN 隧道。此选项会为您提供一个可连接的域名，并启用 PPTP 和 L2TP/IPsec（推荐使用后者）。用户名为 'vpn'，您可以指定自己的密码。您只需在此处启用它，然后在笔记本电脑或手机上提供地址、用户名和密码；连接到 VPN 后，您将获得通往家庭网络的安全加密连接。旅行时也很有用——您将能够通过安全线路浏览互联网，就像从家中连接一样。这也有助于避开某些国家/地区设置的地理限制。

#### 系统 {#system}

- **检查更新**：请始终使用此按钮确保您的设备保持最新。它会检查是否有可用的 RouterOS 更新版本，并安装该更新。
- **密码**：用于设置设备配置页面本身的密码。请确保任何人都无法访问您的路由器配置页面并更改设置。

### 常见问题解答 {#faq}

#### 问：Quickset 与 Webfig 选项卡（其中会出现许多新菜单）有何不同？ {#q-how-is-quickset-different-from-the-webfig-tab-where-a-bunch-of-new-menus-appear}

答：QuickSet 面向只需要让设备快速运行起来的新用户。它在一个位置提供最常用的选项。如果您需要更多选项，请完全不要使用任何 QuickSet 设置；单击 “Webfig” 打开高级配置界面。完整功能将被解锁。

#### 问：我可以同时使用 Quickset 和 Webfig 吗？ {#q-can-i-use-quickset-and-webfig-together}

答：如果您打算使用 Quickset，就只使用 Quickset，反之亦然。虽然可以通过这种方式配置不冲突的设置，但不建议混用这些菜单。Router 模式和 Bridge 模式有什么区别？Bridge 模式会将所有接口加入网桥，允许转发二层数据包（充当集线器/交换机）。在 Router 模式下，数据包通过使用 IP 地址和 IP 路由在三层转发（充当路由器）。

#### 问：在 HomeAP 模式下，2GHz 和 5GHz 网络名称应该相同还是不同？ {#q-in-homeap-mode-should-the-2ghz-and-5ghz-network-names-be-the-same-or-different}

答：如果您希望所有客户端设备（例如电视、手机、游戏主机）都自动选择最合适的网络，请将名称设置为相同。如果您想强制某个客户端设备使用更快的 5GHz 802.11ac 连接，请将名称设置为不同。

#### 问：我可以创建没有安全设置的 AP（无密码），或者在使用 QuickSet 时连接到这样的 AP 吗？ {#q-can-i-create-an-ap-without-security-settings---no-password-or-connect-to-such-ap-while-using-quickset}

答：QuickSet 默认使用 WPA2 预共享密钥。这意味着最小密码长度为 8 个字符，并且设备只能连接到受 WPA2 保护的 AP，或自身充当 AP。对于没有安全设置的配置，您需要使用 WinBox、Webfig 或控制台手动配置。
