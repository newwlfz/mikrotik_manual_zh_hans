本节介绍 60 GHz 无线示例和指南。使用它配置 W60G 点对点和点对多点链路、故障切换以及与距离相关的设置。

<DocCardList />

### 概述 {#summary}

**软件包：** `system`,`wireless`

802.11ad 实现，可通过无线网络提供千兆以太网速度。

通过透明的 AES 加密 60GHz 链路扩展千兆网络，避免常见的有线和无线网络问题。

### 通用接口属性 {#general-interface-properties}

**子菜单：** `/interface/w60g`

:::warning
Wireless Wire kit 设备以预配置的成对形式提供。手动配置为可选项
:::

| 属性 | 说明 |
| :-- | :-- |
| **arp** (*disabled \| enabled \| proxy-arp \| reply-only*；默认：**enabled**) | [`了解更多 >>`](/docs/network-management/arp#arp-modes) |
| **arp-timeout** (*auto \| integer*；默认：**auto**) | ARP 超时时间是指在未收到来自 IP 的数据包后，ARP 记录在 ARP 表中保留的时间。值 **auto** 等于 `/ip/settings` 中的 **arp-timeout** 值，默认为 30s |
| **comment** (*string*；默认：) | 接口的简短描述 |
| **disabled** (*yes \| no*；默认：**yes**) | 接口是否禁用 |
| **frequency** (*58320 \| 60480 \| 62640 \| 64800 \| 66000 \| auto*；默认：**auto**) | 通信使用的频率（仅在 bridge 设备上生效） |
| **isolate-stations** (*yes \| no*；默认：**yes**) | 不允许已连接的客户端之间通信（自 RouterOS 6.41 起） |
| **l2mtu** (*integer [0..7882]*；默认：**1600**) | Layer2 最大传输单元 |
| **mac-address** (*MAC*；默认：) | 无线电接口的 MAC 地址 |
| **mdmg-fix** (*yes \| no*；默认：**no**) | 实验性功能，仅适用于 wAP60Gx3 设备，在某些情况下可提供更好的点对多点稳定性 |
| **mode** (*ap-bridge \| bridge \| sniff \| station-bridge*；默认：**bridge**) | 工作模式 |
| **mtu** (*integer [32..8192]*；默认：**1500**) | Layer3 最大传输单元 |
| **name** (*string*；默认：**wlan60-1**) | 接口名称 |
| **password** (*string*；默认：**randomly generated**) *[敏感参数](/docs/getting-started/configuration-management/list-of-menus-with-sensitive-parameters)* | 用于 AES 加密的密码 |
| **put-stations-in-bridge** (；默认：) | 将新创建的 station 设备接口放入此网桥 |

Station 接口属性：

:::warning
ap-bridge 设备需要 License level 4  [(点击了解更多信息)](/docs/getting-started/routeros-licensing/x86#routeros-license-key-levels)  才能支持多个已连接客户端

### Scan

**子菜单：** `/interface/w60g/scan`

```ros
/interface w60g scan wlan60-1
```

Scan 命令会在 W60G 接口支持的频率范围内搜索并显示可用的 AP。

使用 scan 命令时，接口操作会被禁用（扫描操作期间无线链路会断开）

当前无法执行后台扫描。

### Monitor

**子菜单：** `/interface/w60g/monitor`

```ros
/interface w60g monitor wlan60-1 
connected: yes frequency: 58320 
remote-address: 04:D6:AA:AA:AA:AA 
mcs: 8 
phy-rate: 2.3Gbps 
signal: 80 rssi: -68 
tx-sector: 28 
tx-sector-info: center 
distance: 160.9m
```

Monitor 显示活动连接的当前状态。Distance 测量工具可提供非常精确的距离测量结果。“tx-sector-info”（处于测试阶段的功能）提供当前使用的波束成形模式的信息，并显示指向中心的方向——理论上的最高功率输出点。

### Align

**子菜单：** `/interface/w60g/align`

```ros
/interface w60g align wlan60-1 
connected: yes 
frequency: 58320 
remote-address: 04:D6:AA:AA:AA:AB 
tx-mcs: 6 
tx-phy-rate: 1540.0Mbps 
signal: 70 
rssi: -62 
10s-average-rssi: -63.1 
tx-sector: 62 
tx-sector-info: left 19 degrees, up 26.6 degrees 
rx-sector: 96 
distance: 220.88m 
tx-packet-error-rate: 5%
```

在 align 模式下，两台设备之间交换帧的频率更高，信号质量信息的显示也更频繁。使用“rssi”、“10s-average-rssi”和“tx-sector-info”值可进行更精确的链路对准。设备进入 align 模式时，链路会中断数秒。

### Sniff

Sniff 模式允许捕获附近的 802.11ad 帧。要使用 sniff 模式，需要使用相同的频率，并将接口操作模式设置为 sniff：

```ros
/interface w60g set wlan60-1 mode=sniff
```

现在，该接口可用于 [Tools/Packet Sniffer](/docs/diagnostics-monitoring-and-troubleshooting/packet-sniffer) 捕获数据包。Sniffer 模式不能与常规接口工作模式一起使用。

### 点对多点设置示例 {#point-to-multi-point-setup-example}

所有 MikroTik 设备都可以互连。目前提供四种不同版本的 wAP60G 设备：

- Wireless Wire kit
- wAP 60G
- SXTsq60 Lite60
- wAP 60G AP

And

- Wireless Wire Dish

硬件方面，wAP 设备完全相同，但存在一些软件限制：

**wAP 60G AP** 设计用于 PtMP（Point to Multi Point）设置中的接入点，也可用作 PtP（Point to Point）或 Station 设备。它已配备 level4 许可证，可支持多个连接的客户端。详情请参阅 [RouterOS License Key Levels](/docs/getting-started/routeros-licensing/x86#routeros-license-key-levels)。

**Wireless Wire kit**、**Wireless Wire Dish**、**SXTsq Lite60** 和 **wAP60G** 设备附带 level3 许可证。由于 Wireless Wire Dish 的辐射方向图较窄，因此只能用作客户端设备。

在 Access Point 模式下，要允许多个客户端同时连接，需要升级许可证；但设备可以作为普通 Station 设备连接到 Access Point。

:::warning
配置前，请确保设备运行最新软件版本：[How to upgrade](/docs/getting-started/installation-and-upgrade/upgrade)
:::

透明无线链路的最小配置是匹配 SSID、使用正确模式（bridge || station-bridge），并将 Wireless 和 Ethernet 接口放入同一网桥。

在当前示例中，我们将查看一个使用场景，其中 **wAP60G AP** 用作 Access Point，**wAP60G** 和 **Wireless Wire kit** 设备用作 Station 设备，组成一个由 4 台设备构成的网络。

:::warning
建议更改默认 IP 地址，以避免连接设备时出现问题
:::

**wAP60G AP** 设备预配置了 WISP Bridge [default configuration](/docs/getting-started/configuration-management/default-configurations)。

SSID 以及 Wireless 和 Ethernet 接口之间的网桥已配置完成。建议设置 Wireless 密码并更改 SSID。如果设备已重置，还可以设置正确模式并启用接口。

完成上述所有步骤的单行命令：

```ros
/interface w60g set wlan60-1 password="put_your_safe_password_here" ssid="put_your_new_ssid_here" disabled=no mode=ap-bridge
```

**Wireless Wire 和 wAP60G** 设备预配置了 PTP Bridge 默认配置。

Wireless Wire 设备已随机生成匹配的 SSID 和 Wireless 密码。

Bridge 设备（Bridge 或支持连接一个客户端的 Access point 设备）需要将 Wireless 模式更改为 station-bridge。

可用于将设备设置为客户端模式的单行命令：

```ros
/interface w60g set wlan60-1 password="put_your_safe_password_here" ssid="put_your_new_ssid_here" disabled=no mode=station-bridge
```

如果从空配置开始配置（重置时不使用默认配置）：

需要创建一个包含 Wireless 和 Ethernet 接口的新网桥，并添加 IP 地址以便于访问。

```ros
{ /interface bridge 
add name=bridge1 
/interface bridge port 
add bridge=bridge1 interface=ether1 
add bridge=bridge1 interface=wlan60-1 
/ip address add address=192.168.88.1/24 interface=bridge1 
}
```

对于 Access Point，添加以下行以确保所有连接的站点都放入同一网桥。

```ros
/interface w60g set wlan60-1 put-stations-in-bridge=bridge1
```

每个 Client 设备成功连接后，Access Point 设备上的以下位置将出现一个新条目：

```ros
/interface w60g station print
```

```ros
Flags: X - disabled, R - running 

0 name="wlan60-station-1" parent=wlan60-1 remote-address=AA:AA:AA:AA:AA:AA mtu=1500 mac-address=AA:AA:AA:AA:AA:AB arp=enabled arp-timeout=auto put-in-bridge=parent 

1 name="wlan60-station-2" parent=wlan60-1 remote-address=AA:AA:AA:AA:AB:AA mtu=1500 mac-address=AA:AA:AA:AA:AA:AC arp=enabled arp-timeout=auto put-in-bridge=parent 

2 name="wlan60-station-3" parent=wlan60-1 remote-address=AA:AA:AA:AA:AC:AA mtu=1500 mac-address=AA:AA:AA:AA:AA:AD arp=enabled arp-timeout=auto put-in-bridge=parent 

3 name="wlan60-station-4" parent=wlan60-1 remote-address=AA:AA:AA:AA:AD:AA mtu=1500 mac-address=AA:AA:AA:AA:AA:AE arp=enabled arp-timeout=auto put-in-bridge=parent 
```

可为每个客户端应用独立设置（队列、VLAN、防火墙规则等），从而提供更灵活的配置。

要限制同一网桥内的客户端间通信，可在 Access Point 设备上使用 isolate-stations 选项：

```ros
/interface w60g set wlan60-1 isolate-stations=yes
```

### 故障排除和建议 {#troubleshooting-and-recommendations}

MikroTik 60GHz 解决方案的功能包括对 ATPC（Adaptive Transmit Power Control）的支持

##### 物理属性 {#physical-properties}

802.11ad 标准使用的无线频率的大气衰减非常高。部署链路前应考虑到这一点。

Wireless Wire kit 已在最远 200 米的距离上经过测试。

Wireless Wire dish kit 已在最远 2500 米的距离下进行测试。为确保稳定性和全速可用性，建议该 kit 的使用距离不超过 1500 米。

wAP60G 设备配备相控阵 60° 波束成形天线，可在短距离内帮助信号绕过障碍物，但在较远距离下，保持视距畅通仍然至关重要。

LHG60G 设备的单个辐射方向图小于 1 度（水平和垂直方向均如此）。所有方向图组合后，在水平和垂直平面上均可提供接近 3 度的覆盖范围。波束成形算法会针对每种情况计算最佳方向图。波束宽度和方向取决于所使用的预定义校准扇区。

##### 连接问题 {#connection-issues}

要连接设备，设备之间需要具备直视条件，客户端设备上的“scan-list”需要包含 AP 设备上使用的“frequency”。LHG60 设备需要非常精确的对准，才能在较远距离获得最佳性能。

##### Wireless Wire 套件的配置重置 {#configuration-reset-for-wireless-wire-kits}

Reset 按钮的功能与其他设备相同，详情请参阅[此处](/docs/getting-started/configuration-management/routeros-configuration-reset)。

**启动时按住按钮 5 秒（USR LED 开始闪烁）** - 重置为受密码保护状态。

**启动时按住按钮 10 秒（USR LED 闪烁后常亮）** - 完全移除配置。

:::warning
完全移除配置后，只能建立 [mac-telnet](/docs/management-tools/mac-server) 连接
:::
