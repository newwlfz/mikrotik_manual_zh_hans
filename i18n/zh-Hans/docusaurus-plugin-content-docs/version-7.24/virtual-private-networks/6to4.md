6to4 是一种特殊机制，无需显式配置隧道接口即可通过 IPv4 网络传输 IPv6 数据包。它尤其适用于通过不支持 IPv6 的网络连接两个或更多 IPv6 网络。6to4 机制有两种不同方式。如果未配置 *remote-address*，当 IPv6 数据包的前 16 位为 *2002* 时，路由器将直接使用后续 32 位作为目标（IPv4 地址转换为十六进制），在 IPv4 上封装并发送该数据包。另一种情况下，IPv6 数据包将直接发送到 IPv4 *remote-address*。
**子菜单：** `/interface/6to4`

## 属性说明 {#property-description}

| 属性 | 说明 |
| :-- | :-- |
| **clamp-tcp-mss** (*yes \| no*；默认：**yes**) | 控制是否更改收到的 TCP SYN 数据包的 MSS 大小。启用后，如果当前 MSS 大小超过隧道接口 MTU（考虑 TCP/IP 开销），路由器将更改收到的 TCP SYN 数据包的 MSS 大小。收到的封装数据包仍包含原始 MSS，只有在解封装后才会更改 MSS。 |
| **comment** (*string*；默认：) | 接口的简短描述。 |
| **disabled** (*yes \| no*；默认：**no**) | 项目是否禁用。 |
| **dont-fragment** (*inherit \| no*；默认：**no**) | 是否在相关数据包中包含 DF 位：<br/><em>no</em> - 必要时分片，<em>inherit</em> - 使用原始数据包的 Don't Fragment 标志。<br/>（未设置 Don't Fragment：inherit - 数据包可能被分片）。 |
| **dscp** (*integer: 0-63*；默认：**inherit**) | 数据包的 DSCP 值。Inherited 选项表示 DSCP 值将继承自即将被封装的数据包。 |
| **ipsec-secret** (*string*；默认：) *[sensitive](/docs/getting-started/configuration-management/list-of-menus-with-sensitive-parameters)* | 指定 secret 后，路由器会向 remote-address 添加动态 IPsec peer，并使用预共享密钥和策略（默认 phase2 使用 sha1/aes128cbc）。 |
| **keepalive** (*integer[/time],integer 0..4294967295*；默认：**0,0**) | 隧道 keepalive 参数用于设置时间间隔，在该间隔内，即使隧道远端宕机，隧道 running 标志仍会保持。如果配置的时间和重试次数均失败，则移除接口 running 标志。参数按以下格式写入：`KeepaliveInterval,KeepaliveRetries`，其中 `KeepaliveInterval` 是时间间隔，`KeepaliveRetries` 是重试次数。默认禁用 keepalive（0 秒，0 次重试）。 |
| **local-address** (*IP*；默认：) | 数据包的源地址，为路由器本地地址。 |
| **mtu** (*integer*；默认：**auto**) | Layer3 最大传输单元。 |
| **name** (*string*；默认：) | 接口名称。 |
| **remote-address** (*IP*；默认：) | 6to4 隧道远端的 IP 地址。如果未指定，将从 2002::/16 网关地址推导出 IPv4 地址。 |

## 配置示例 {#configuration-examples}

### 简单的 6to4 隧道封装（当前不可用） {#simple-6to4-tunnel-encapsulation-currently-not-working}

![](/img/01fb25e7c82ced9c.webp)

可以通过使用分配的 2002::/16 地址空间，在 IPv4 网络上直接路由 IPv6 数据包。所有 6to4 节点都必须具有可达的 IPv4 地址：如果通过 Internet 运行此配置，则所有 IPv4 地址都必须是公网地址。

#### R1 配置 {#r1-configuration}

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个 IPv6 地址，前 16 位为“2002”，接下来的 32 位为十六进制格式的 IPv4 地址。例如，如果路由器的 IP 地址为 10.0.1.1，则 IPv6 地址为 2002:A00:101::

```ros
/ipv6/address
add address=2002:a00:101::/128 advertise=no interface=6to4-tunnel1
```

添加一条经由 6to4-tunnel 接口通往专门分配的 6to4 隧道地址范围的路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### R2 配置 {#r2-configuration}

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

按照与 R1 相同的原则分配一个 IPv6 地址。在本例中，10.0.2.1 转换为 2002:A00:201::。

```ros
/ipv6/address
add address=2002:a00:201::/128 advertise=no interface=6to4-tunnel1
```

这一侧也需要 6to4 路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### 测试 {#testing}

配置两台设备后，如果 IPv6 地址生成正确，应能 ping 通这些地址。

From R1:

```ros
/ping 2002:a00:201::
```

### Hurricane Electric Tunnel Broker 示例 {#hurricane-electric-tunnel-broker-example}

以下示例将展示如何通过 6to4 隧道，使 RouterOS 设备经由 IPv4 网络获得 IPv6 连接。

要创建隧道，必须具有公网 IPv4 地址，并允许来自 Tunnel Broker IPv4 服务器的 ping。

使用 [Hurricane Electric Tunnel Broker](https://tunnelbroker.net) 创建隧道时，将获得一个已路由的 /64 IPv6 前缀以及设置隧道所需的其他信息。

*![](/img/0c5a58e7258874ec.webp)*

*此示例假定您的公网 IPv4 地址为 194.105.56.170*

Hurricane Electric 在“Example Configurations”部分提供了可直接用于 RouterOS 的命令：

```ros
/interface/6to4
add comment="Hurricane Electric IPv6 Tunnel Broker" disabled=no local-address=194.105.56.170 mtu=1280 name=sit1 remote-address=216.66.80.90
/ipv6/route
add comment="" disabled=no distance=1 dst-address=2000::/3 gateway=2001:470:27:37e::1 scope=30 target-scope=10
/ipv6/address
add address=2001:470:27:37e::2/64 advertise=no disabled=no eui-64=no interface=sit1
```

这些命令将设置隧道本身，路由器将能够连接到 IPv6 主机，但最终用户设备（计算机、平板电脑、手机）尚不具备 IPv6 连接。

要为用户分配 IPv6 地址，必须将 Routed IPv6 Prefix 添加到内部接口（默认为 bridge-local）。

```ros
/ipv6/address/add address=2001:470:28:37e:: interface=bridge-local advertise=yes
```

通过网络发现启用 DNS 服务器通告

```ros
/ipv6/nd/set [ find default=yes ] advertise-dns=yes
```

最后添加 IPv6 DNS 服务器（这些是 Google 公共 DNS 服务器，也可以使用 Hurricane Electric 提供的服务器：2001:470:20::2）。

```ros
/ip/dns/set allow-remote-requests=yes servers=2001:4860:4860::8888,2001:4860:4860::8844
```

之后在设备上启用 IPv6，即可具备 IPv6 连接。可使用 [https://test-ipv6.com](https://test-ipv6.com/) 测试 IPv6 连接。
