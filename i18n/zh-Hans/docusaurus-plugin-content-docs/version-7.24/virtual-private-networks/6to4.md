**子菜单：** `/interface/6to4`

## 属性说明 {#property-description}

| 属性 | 描述 |
| :-- | :-- |
| **clamp-tcp-mss** (*yes \| no*; 默认：**yes**) | 控制是否更改接收到的 TCP SYN 报文的 MSS 大小。启用后，如果当前 MSS 大小超过隧道接口 MTU（考虑 TCP/IP 开销），路由器将更改接收到的 TCP SYN 报文的 MSS 大小。接收到的封装报文仍将包含原始 MSS，并且只有在解封装后才会更改 MSS。 |
| **comment** (*string*; 默认值: ) | 接口的简短描述。 |
| **disabled** (*yes \| no*; 默认：**no**) | 项目是否已禁用。 |
| **dont-fragment** (*inherit \| no*; 默认值：**no**) | 是否在相关数据包中包含 DF 位： *no* - 如有需要则分片，*inherit* - 使用原始数据包的 Don't Fragment 标志。  （不带 Don't Fragment：inherit - 数据包可能被分片）。 |
| **dscp** (*integer: 0-63*; 默认：**inherit**) | 报文的 DSCP 值。Inherited 选项表示 DSCP 值将从将要被封装的报文中继承。 |
| **ipsec-secret** (*string*; 默认值：) *[敏感](../getting-started/configuration-management/list-of-menus-with-sensitive-parameters.md)* | 指定 secret 后，路由器会向 remote-address 添加动态 IPsec 对等体，并使用预共享密钥和策略（默认情况下 phase2 使用 sha1/aes128cbc）。 |
| **keepalive** (*integer[/time],integer 0..4294967295*; 默认：**0,0**) | 隧道 keepalive 参数设置时间间隔，在此期间即使隧道远端断开，隧道运行标志也将保持。如果配置的时间和重试次数失败，则移除接口运行标志。参数按以下格式编写：`KeepaliveInterval,KeepaliveRetries`，其中 `KeepaliveInterval` 是时间间隔，`KeepaliveRetries` 是重试次数。默认情况下 keepalive 处于禁用状态（0 秒，0 次重试）。 |
| **local-address** (*IP*; 默认：) | 报文的源地址，且位于路由器本地。 |
| **mtu** (*integer*; 默认：**auto**) | 三层最大传输单元。 |
| **name** (*string*; 默认：) | 接口名称。 |
| **remote-address** (*IP*; 默认：) | 6to4 隧道远端的 IP 地址。如果未指定，IPv4 地址将从 2002::/16 网关地址派生。 |

## 配置示例 {#configuration-examples}

### 简单的 6to4 隧道封装（目前不可用） {#simple-6to4-tunnel-encapsulation-currently-not-working}

![](/img/01fb25e7c82ced9c.webp)

通过利用 2002::/16 分配的地址空间，可以简单地在 IPv4 网络上路由 IPv6 报文。所有 6to4 节点都必须具有可达的 IPv4 地址——如果您在互联网上运行此设置，则所有 IPv4 地址都必须是公网地址。

#### R1 配置 {#r1-configuration}

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个 IPv6 地址，其中前 16 位为 '2002'，接下来的 32 位为十六进制格式的 IPv4。例如，如果路由器的 IP 地址是 10.0.1.1，则 IPv6 地址是 2002:A00:101::

```ros
/ipv6/address
add address=2002:a00:101::/128 advertise=no interface=6to4-tunnel1
```

添加一条通过 6to4-tunnel 接口指向专门分配的 6to4 隧道范围的路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### R2 配置 {#r2-configuration}

创建 6to4 隧道接口：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一个按照与 R1 相同原则生成的 IPv6 地址。在此例中，10.0.2.1 转换为 2002:A00:201::

```ros
/ipv6/address
add address=2002:a00:201::/128 advertise=no interface=6to4-tunnel1
```

这一侧同样需要 6to4 路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### 测试 {#testing}

配置两台设备后，如果 IPv6 地址生成正确，应该可以 ping 通这些地址。

从 R1：

```ros
/ping 2002:a00:201::
```

### Hurricane Electric Tunnel Broker 示例 {#hurricane-electric-tunnel-broker-example}

以下示例将展示如何通过 6to4 隧道，在 IPv4 网络上让 RouterOS 设备获得 IPv6 连接性。

要能够创建隧道，您必须拥有公网 IPv4 地址，并启用来自 Tunnel Broker IPv4 服务器的 ping。

当您使用 [Hurricane Electric Tunnel Broker](https://tunnelbroker.net) 创建隧道时，您将获得一个已路由的 /64 IPv6 前缀以及设置隧道所需的其他信息。

*![](/img/0c5a58e7258874ec.webp)*

*本示例假定您的公网 IPv4 地址是 194.105.56.170*

Hurricane Electric 在 '示例配置' 部分提供了可直接用于 RouterOS 的命令：

```ros
/interface/6to4
add comment="Hurricane Electric IPv6 Tunnel Broker" disabled=no local-address=194.105.56.170 mtu=1280 name=sit1 remote-address=216.66.80.90
/ipv6/route
add comment="" disabled=no distance=1 dst-address=2000::/3 gateway=2001:470:27:37e::1 scope=30 target-scope=10
/ipv6/address
add address=2001:470:27:37e::2/64 advertise=no disabled=no eui-64=no interface=sit1
```

这些命令将设置隧道本身——路由器将能够连接到 IPv6 主机，但终端用户设备（计算机、平板电脑、手机）尚不具备 IPv6 连接性。

要能够为客户端分配 IPv6 地址，您必须将 Routed IPv6 Prefix 添加到内部接口（默认为 bridge-local）。

```ros
/ipv6/address/add address=2001:470:28:37e:: interface=bridge-local advertise=yes
```

通过网络发现启用 DNS 服务器通告

```ros
/ipv6/nd/set [ find default=yes ] advertise-dns=yes
```

最后添加 IPv6 DNS 服务器（这些是 Google 公共 DNS 服务器，您也可以使用 Hurricane Electric 提供的 2001:470:20::2）。

```ros
/ip/dns/set allow-remote-requests=yes servers=2001:4860:4860::8888,2001:4860:4860::8844
```

之后在您的设备上启用 IPv6，您就应该具备 IPv6 连接性。[https://test-ipv6.com](https://test-ipv6.com/) 可用于测试 IPv6 连接性。
