## 连接到交换机 {#connecting-to-the-switch}

打开 Web 浏览器并输入交换机的 IP 地址（默认为 192.168.88.1），将显示登录界面。交换机也可以运行 DHCP 客户端，请检查 DHCP 服务器是否分配了其他 IP 地址。

![Swos login css106](/img/776fa0e1c75d6b6b.webp)

SwOS 默认 IP 地址：**192.168.88.1**，用户名：**admin**，无密码。

[MikroTik Neighbor Discovery](/docs/system-information-and-utilities/neighbor-discovery) 可用于发现 MikroTik 交换机的 IP 地址。不支持 LLDP。

## 接口概览 {#interface-overview}

SwOS 接口菜单由多个选项卡组成：Link、SFP、Forwarding、RST、Statistics、Errors、VLAN、VLANs、Hosts、IGMP Groups、SNMP、ACL、System 和 Upgrade。

SwOS 配置工具中的按钮说明：

- **Append** - 在列表末尾添加新项目
- **Apply All** - 应用当前配置更改
- **Cut** - 从列表中移除项目
- **Clear** - 重置项目属性
- **Discard Changes** - 移除未保存的配置
- **Insert** - 向列表添加新项目（将其置于当前项目之前）
- **Sort** - 按 VLAN-ID 排序 VLAN 表；按 MAC 地址排序主机表
- **Change Password** - 更改交换机密码
- **Logout** - 退出当前交换机
- **Reboot** - 重启交换机
- **Reset Configuration** - 将配置重置为出厂默认值
- **Choose File** - 浏览升级文件或备份文件
- **Upgrade** - 使用所选文件升级交换机固件
- **Download & Upgrade** - 自动尝试下载并升级固件，运行 Web 浏览器的 PC 应能访问 Internet
- **Restore Backup** - 使用所选备份文件恢复交换机
- **Save Backup** - 从交换机生成并下载备份文件

> **Note:** 每个 RouterBOARD 交换机系列都有各自的固件，无法安装在其他系列型号上！CSS106-5G-1S（RB260GS）和 CSS106-1G-4P-1S（RB260GSP）支持 SwOS v2.0 及更高版本。升级设备时，它将首先加载主固件，然后进行升级。如果选择了错误的固件文件，设备将继续使用主固件运行，并且你可以选择正确的文件。

PoE 设置用于更改 CSS106-1G-4P-1S 的 port2-port5 上的 Power over Ethernet 输出，并显示 PoE 状态和测量值。

![740px Swospoe2](/img/edfe6029282de3b7.webp)

| 属性 | 说明 |
| --- | --- |
| **PoE Out** | 设置端口的 PoE 输出模式：<br/><code>off</code> - 关闭所有检测和 PoE 输出<br/><code>auto</code> - 根据备用线对上的电阻进行检测，以检查端口是否具备 PoE 能力。要开启端口，测量值应在 3kΩ 至 26.5kΩ 范围内<br/><code>on</code> - 无论端口电阻如何，均启用 PoE 输出。<em><strong>请谨慎使用该选项，否则可能损坏连接的设备！</strong></em><br/><code>calibr</code> - 手动重新校准端口 PoE 输出。如果连接的设备偶尔出现供电问题，可能需要执行此操作。 |
| **PoE Priority** | 端口的 PoE 供电优先级。如果安装超出可用功率预算，将首先关闭优先级最低的端口。`1` - 最高优先级端口；`4` - 最低优先级端口 |
| **PoE Status** | 端口当前的 PoE 输出状态：<br/><code>disabled</code> - PoE 输出已关闭<br/><code>waiting for load</code> - <code>auto</code> 模式检测到电阻超出范围，以开启 PoE 输出<br/><code>powered on</code> - PoE 输出已开启<br/><code>short circuit</code> - 如果检测到短路，将关闭 PoE 输出，以确保受电设备不会受到进一步损坏，且供电设备不会损坏<br/><code>voltage too low</code> - 供电电压不足，无法通过 PoE 输出开启设备<br/><code>current too low</code> - 供电电流不足，无法通过 PoE 输出开启设备<br/><code>waiting for cable disconnect</code> - 使用 <code>calibr</code> 手动重新校准时检测到已连接设备，并等待断开连接以完成重新校准过程 |
| **PoE Current** | 显示端口当前用量，单位为毫安 |
| **PoE Power** | 显示端口的 PoE 输出功率，单位为瓦 |

## Forwarding

Forwarding Tab 提供交换机端口之间的高级转发选项，包括端口隔离、端口锁定、端口镜像和出口带宽限制功能。每个端口的入口速率和广播流量速率可通过 [Access Control List](#acl) 设置 `Rate` 进行配置。ACL 每个条目必须只有一个端口，才能正确提供带宽限制。

![740px Swos forwarding2](/img/ca2d7131f8465cde.webp)

| 属性 | 说明 |
| --- | --- |
| **Forwarding** | 转发表 - 允许或限制特定端口之间的流量 |
| **Port Lock** | <code>Port Lock</code> - 启用或禁用该端口的 MAC 地址学习。启用该选项时，将限制 MAC 地址学习，应配置静态 MAC 地址<br/><code>Lock On First</code> - 启用或禁用该端口的 MAC 地址学习（仍会学习从收到的第一个数据包中获取的 MAC 地址） |
| **Port Mirroring** | <code>Mirror Ingress</code> - 是否必须复制进入该端口的流量并转发到镜像目标端口<br/><code>Mirror Egress</code> - 是否必须复制离开该端口的流量并转发到镜像目标端口<br/><code>Mirror To</code> - 镜像目标端口 |
| **Bandwidth Limit** | `Egress Rate` - 限制离开该端口的流量（bps） |

## RSTP

每个端口和全局 RSTP 配置及监控均可在 RSTP 菜单中使用。

![Swos RSTP css106](/img/001984d0b4ba3e55.webp)

| 属性 | 说明 |
| --- | --- |
| **RSTP** | 启用或禁用该端口的 STP/RSTP 功能 |
| **Mode** | 显示特定端口上的 STP/RSTP 功能模式（只读）：<br/><code>RSTP</code><br/><code>STP</code> |
| **Role** | 显示特定端口角色（只读）：<br/><code>root</code> - 面向根网桥的端口，用于转发来自或发往根网桥的流量<br/><code>alternate</code> - 面向根网桥的端口，但不会转发流量（根端口的备份）<br/><code>backup</code> - 背向根网桥的端口，但不会转发流量（非根端口的备份）<br/><code>designated</code> - 背向根网桥的端口，并将转发流量<br/><code>disabled</code> - 严格来说不属于 STP 的端口（RSTP 功能已禁用） |
| **Root Path Cost** | 显示面向根网桥的端口的根路径开销（只读） |
| **Type** | <code>edge</code> - 不应接收任何 BPDU 的端口，应连接到终端站（只读）<br/><code>point-to-point</code> - 工作在全双工链路上的端口，可成为 STP 的一部分并处于转发状态（只读） |
| **State** | 显示每个端口状态（只读）：<br/><code>forwarding</code> - 端口参与流量转发并学习 MAC 地址，正在接收 BPDU<br/><code>discarding</code> - 端口不参与流量转发且不学习 MAC 地址，正在接收 BPDU<br/><code>learning</code> - 端口不参与流量转发，但正在学习 MAC 地址 |
| **Bridge Priority (hex)** | 用于选择 Root Bridge 的 RSTP 网桥优先级 |
| **Port Cost Mode** | 根据链路速率自动检测 RSTP 端口开销有两种方法。<br/><code>short</code>: 10G - 2；1G - 4；100M - 10；10M - 100<br/><code>long</code>: 10G - 2000；1G - 20000；100M - 200000；10M - 2000000 |
| **Forward Reserved Multicast** | 是否转发位于 <strong>01:80:C2:00:00:0x</strong> 范围内的 IEEE 保留组播 MAC 地址。符合 R/M/STP 标准的交换机应避免转发这些数据包。<br/><br/>如果启用该设置，SwOS 将转发保留的组播 MAC 数据包并禁用 RSTP：<br/>- 交换机将不处理传入的 BPDU（Bridge Protocol Data Units）<br/>- 也不会发送自身的 BPDU<br/>- Bridge Priority 和每端口 RSTP 配置设置将不再生效。<br/><br/>启用保留 MAC 地址转发可能会影响依赖这些地址的某些协议。建议仅在绝对必要时启用转发，例如透明桥接场景（如延长长链路、将网桥用作介质转换器或进行网络分析）。<br/><br/>值得注意的 MAC 地址和协议示例（由 RouterOS 使用）：<br/><code>01:80:C2:00:00:00</code> - Spanning Tree Protocol（STP）<br/><code>01:80:C2:00:00:01</code> - Ethernet Flow Control<br/><code>01:80:C2:00:00:02</code> - Link Aggregation Control Protocol（LACP）<br/><code>01:80:C2:00:00:03</code> - Dot1x 客户端和服务器<br/><code>01:80:C2:00:00:08</code> - Spanning Tree Protocol（用于 802.1ad 网桥，使用 <code>ether-type=0x88a8</code>）<br/><code>01:80:C2:00:00:0D</code> - Multiple VLAN Registration Protocol（用于 802.1ad 网桥，使用 <code>ether-type=0x88a8</code>）<br/><code>01:80:C2:00:00:0E</code> - Link Layer Discovery Protocol、Multi-chassis Link Aggregation Group 和 Precision Time Protocol<br/><br/>Flow Control MAC 地址 <code>01:80:C2:00:00:01</code> 是一个例外——SwOS 不会转发它。 |
| **Root Bridge** | 网络中选定 Root Bridge 的优先级和 MAC 地址（只读） |

## VLAN 和 VLAN {#vlan-and-vlans}

交换机端口的 VLAN 配置。

![740px Swos vlan2](/img/5d51b5ec225f57e1.webp)

| 属性 | 说明 |
| --- | --- |
| **VLAN Mode** | 入站端口的 VLAN 模式：<br/><code>disabled</code> - 不使用 VLAN 表；交换机忽略带标签数据包中的 VLAN 标签部分<br/><code>optional</code> - 对 VLAN 表 ID 中不存在的 VLAN 标签数据包，按不带 VLAN 标签的数据包处理<br/><code>enabled</code> - 丢弃 VLAN 表 ID 中不存在的 VLAN 标签数据包。不带 VLAN 标签的数据包按带有 `Default VLAN ID` 的带标签数据包处理<br/><code>strict</code> - 与 <code>enabled</code> 相同，但还会检查入站接口是否支持 VLAN（丢弃 VLAN 表 ID 中不存在的 VLAN 标签数据包和入站端口） |
| **VLAN Receive** | 定义入站端口允许的数据包类型：<br/><code>any</code> - 允许指定端口上的带标签和不带标签数据包<br/><code>only tagged</code> - 仅允许带 VLAN 标签的数据包<br/><code>only untagged</code> - 仅允许不带 VLAN 标签的数据包 |
| **Default VLAN ID** | 交换机将不带标签的数据包和带有“Default VLAN ID”标签的入站数据包都视为带有该 VLAN ID 的标签数据包。当数据包的 VLAN ID 与“Default VLAN ID”匹配时，也用于去除出站流量的标签。只有在出站端口指定了 `VLAN Header = add if missing` 时，才会添加 VLAN 标签本身 |
| **Force VLAN ID** | 是否对带 VLAN 标签的入站数据包应用 `Default VLAN ID` |
| **VLAN Header** | <code>leave as is</code> - 如果存在 VLAN 头，则保持不变<br/><code>always strip</code> - 如果存在 VLAN 头，则从数据包中移除<br/><code>add if missing</code> - 如果不存在 VLAN 头，则将其添加到数据包中（VLAN ID 将为入站端口的 <code>Default VLAN ID</code>） |

> **说明：** 运行 SwOS 2.12 的 CSS106 设备在端口上启用 VLAN 过滤时（VLAN Mode 为 **enabled** 或 **strict**），可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

> **说明：** VLAN 模式 `enabled` 和 `strict` 要求 VLAN 表中存在 VLAN ID 1，以允许不带标签的流量访问交换机本身。

VLAN 表指定带有 IEEE 802.1Q 标签的数据包的转发规则。基本上，该表包含将特定 VLAN 标签 ID 映射到一组一个或多个端口的条目。带 VLAN 标签的数据包通过对应表条目中设置的一个或多个端口离开交换机。VLAN 表与目标 MAC 查找配合使用，以确定出站端口。VLAN 表最多支持 250 个条目。

![Swos vlan css106](/img/cdfe40f140124a72.webp)

| 属性 | 说明 |
| --- | --- |
| **VLAN ID** | 数据包的 VLAN ID |
| **IVL** | 启用或禁用独立 VLAN 学习（IVL） |
| **IGMP Snooping** | 在指定 VLAN 上启用或禁用 IGMP Snooping。启用时，交换机会监听来自指定 VLAN 的 IGMP Join 和 Leave 请求，并仅将流量转发到已从指定 VLAN 发送 IGMP 成员请求的端口。禁用时，交换机会向所有 VLAN 成员端口泛洪组播流量。 |
| **Ports** | 每个端口对每个 VLAN ID 都有单独的 *VLAN header* 选项。根据 *VLAN mode*，如果在此表中进行查找，则数据包的出站操作由该选项处理。**VLAN tab** 中的出站选项将被忽略。 |

### VLAN 配置示例 {#vlan-configuration-examples}

#### Trunk 和 Access 端口 {#trunk-and-access-ports}

![Access ports small](/img/d235e6fd5caac3d6.webp)

1. 在 System 菜单中启用独立 VLAN 学习（IVL）。

![Css106 ivl](/img/69cce788e8633553.webp)

1. 在 VLANs 菜单中添加 VLAN 条目，指定端口成员关系，并启用 IVL。可以使用默认的“leave as is”端口设置；可通过“Default VLAN ID”设置更改打标签和去标签行为，请参阅下一步。

![Css access trunk vlans](/img/866c15add91965c4.webp)

1. 在 VLAN 菜单中，在计划的 access 端口上配置 Default VLAN ID（untagged），选择正确的 VLAN Receive 设置（Port2 only tagged，Port3-5 only untagged），并启用严格 VLAN 过滤，以确保只有允许的 VLAN 可以通过端口。

![Css106 access vlan](/img/894c635777800fe4.webp)

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤时（VLAN Mode **enabled** 或 **strict**）可以过滤 RSTP BPDU 数据包。使用 SwOS 2.13 版本时，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

#### Trunk 和 Hybrid 端口 {#trunk-and-hybrid-ports}

![Hybrid ports small](/img/238fa201dac1535f.webp)

1. 在 System 菜单中启用独立 VLAN 学习（IVL）。

![Css106 ivl 1](/img/69cce788e8633553.webp)

1. 在 VLANs 菜单中添加 VLAN 条目，指定端口成员关系，并启用 IVL。可以使用默认的“leave as is”端口设置；可通过“Default VLAN ID”设置更改打标签和去标签行为，请参阅下一步。

![Css hybrid vlan](/img/05a39054ed03bffb.webp)

1. 在 VLAN 菜单中，为规划为 hybrid 的端口配置 Default VLAN ID（用于 untagged VLAN），选择正确的 VLAN Receive 设置（Port2 仅 tagged，Port3-5 为 any），并启用严格 VLAN 过滤，以确保只有允许的 VLAN 可以通过端口。

![Css hybrid vlans](/img/b285dc0d4f377d42.webp)

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤时（VLAN Mode 为 **enabled** 或 **strict**）可以过滤 RSTP BPDU 数据包。使用 SwOS 2.13 版本时，建议将 trunk 端口的 VLAN Receive 设置为 **any**。

#### 管理访问 {#management-access}

在本示例中，将创建 VLAN 200 上的交换机管理访问。配置方案与“**Trunk and Access Ports**”相同，步骤 **1.、2.、3.** 相同。额外的第 **4** 步需要在 System 菜单中指定管理 VLAN ID。应用配置后，交换机将仅响应 Port2 上 tagged VLAN 200 的数据包以及 Port3 上的 untagged 数据包。DHCP 客户端也将在指定的 VLAN ID 中工作。

![Css106 system vlan](/img/ebd3dc6d62accb2d.webp)

> **警告：** 如果 VLAN 设置配置不正确，更改管理 VLAN 可能会完全禁用对交换机管理的访问。更改此设置前请保存配置备份，如果管理访问丢失，请使用 [Reset](#reset)。

## Hosts

此表表示动态学习到的 MAC 地址到端口的映射条目。它可以包含两类条目：动态和静态。动态条目会自动添加——这也称为学习过程：当交换机从某个端口收到数据包时，它会将该数据包的源 MAC 地址 X 以及收到该数据包的端口添加到主机表中，因此当收到目的 MAC 地址为 X 的数据包时，它知道应将数据包转发到哪个端口。如果主机表中不存在目的 MAC 地址，则会将数据包转发到组中的所有端口（flood）。动态条目约 5 分钟后超时。

CSS106 系列交换机支持 2048 个主机表条目。

![Swos hosts css106](/img/a579ada46273a14f.webp)

| 属性 | 描述 |
| --- | --- |
| **Port** | 应将数据包转发到的端口（只读） |
| **MAC** | 学习到的 MAC 地址（只读） |
| **VLAN ID** | 学习到的 VLAN ID（只读） |

### 静态主机 {#static-hosts}

如果已存在具有相同 MAC 地址的动态条目，静态条目将接管动态条目。添加静态条目还可使用其他功能。

![740px Swos static2](/img/b02ac39742098a2b.webp)

| 属性 | 说明 |
| --- | --- |
| **Ports** | 数据包应转发到的端口 |
| **MAC** | MAC 地址 |
| **VLAN ID** | VLAN ID |
| **Drop** | 可以丢弃来自特定端口且具有特定 MAC 地址的数据包 |
| **Mirror** | 可以克隆数据包并发送到 mirror-target 端口 |

## IGMP 组 {#igmp-groups}

首先，在 System 选项卡下启用该选项。

![Swos igmp2 css106](/img/794ba62a3ae97326.webp)

可用的 IGMP snooping 数据位于 IGMP Group 选项卡下。

![Swos igmp css106](/img/6064170c408de037.webp)

![Swos igmp3 css106](/img/a4f9d8c735aed4fb.webp)

## SNMP

SwOS 支持 SNMP v1 和 v2c（响应 GetRequest、GetNextRequest 和 GetBulkRequest），并使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（仅用于 health、PoE-out 和 SFP 诊断）。不支持 SNMP trap 和写入 SwOS 配置。

可用的 SNMP 数据：

- 系统信息
- 系统运行时间
- 端口状态
- 接口统计
- 主机表信息

![Swos snmp2](/img/f3b87569bbcad587.webp)

| 属性 | 说明 |
| --- | --- |
| **Enabled** | 启用或禁用 SNMP 服务 |
| **Community** | SNMP community 名称 |
| **Contact Info** | NMS 的联系人信息 |
| **Location** | NMS 的位置信息 |

## ACL

访问控制列表（ACL）规则表是一个非常强大的工具，可基于 L2、L3 和 L4 协议头字段条件实现线速数据包过滤、转发和 VLAN 标记。SwOS 允许你实现数量有限的访问控制列表规则（32 条简单规则，仅使用 L2 条件；16 条规则，同时使用 L2 和 L3 条件；或 8 条高级规则，使用所有 L2、L3 和 L4 条件）。每条规则包含条件部分和动作部分。

![740px Swos acl2](/img/0bd3d4c1437ed824.webp)

**条件参数**

| 属性 | 说明 |
| --- | --- |
| **From** | 数据包进入的端口 |
| **MAC Src** | 源 MAC 地址和掩码 |
| **MAC Dst** | 目的 MAC 地址和掩码 |
| **Ethertype** | 封装在以太网帧 payload 中的协议 |
| **VLAN** | VLAN 头是否存在：`any` / `present` / `not present` |
| **VLAN ID** | VLAN tag ID |
| **Priority** | VLAN tag 中的优先级 |
| **IP Src** (IP/netmask:port) | 源 IPv4 地址、网络掩码和 L4 端口号 |
| **IP Dst** (IP/netmask:port) | 目的 IPv4 地址、网络掩码和 L4 端口号 |
| **Protocol** | IP 协议 |
| **DSCP** | IP DSCP 字段 |

**动作参数**

| 属性 | 说明 |
| --- | --- |
| **Redirect To** | 是否强制使用新的目标端口（如果启用“Redirect To”且“Redirect To Ports”中未指定端口，则数据包将被丢弃） |
| **Redirect To Ports** | 重定向目标端口 |
| **Mirror** | 克隆数据包并将其发送到镜像目标端口 |
| **Rate** | 限制带宽（bps） |
| **Set VLAN ID** | 如果存在 VLAN 标签，则更改 VLAN 标签 ID |
| **Priority** | 如果存在 VLAN 标签，则更改 VLAN 标签优先级位 |

## Reset

CSS106-5G-1S 和 CSS106-1G-4P-1S 内置备份 SwOS 固件，可在标准固件损坏或升级失败时加载：

- 设备启动期间按住 Reset 按钮几秒钟，将重置配置并加载备份固件。
- 加载备份固件后，可以使用 Web 浏览器连接到 192.168.88.1（或 DHCP 服务器租用的地址）并安装新的 SwOS 固件。
