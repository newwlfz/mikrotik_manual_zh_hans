## 功能 {#features}

| 功能 | 描述 |
| --- | --- |
| **转发** | 全非阻塞线速交换；主机表中最多 2k 条 MAC 表项；转发数据库基于 SVL 或 IVL 工作；端口隔离；端口锁定；Jumbo 帧支持 - 9198 bytes |
| **生成树协议** | 支持 RSTP |
| **组播转发** | 支持 IGMP Snooping |
| **镜像** | 基于端口的镜像 |
| **VLAN** | 完全兼容 IEEE802。基于端口的 VLAN；VLAN 过滤 |
| **服务质量 (QoS)** | 入方向流量限制（通过 ACL）；出方向流量限制 |
| **Access Control List** | 入口 ACL 表；最多 32 条 ACL 规则（受 SwOS 限制）；基于端口、L2、L3、L4 协议头字段进行分类；ACL 动作包括过滤、转发和修改协议头字段 |

## 连接到交换机 {#connecting-to-the-switch}

打开 Web 浏览器，输入交换机的 IP 地址（默认为 192.168.88.1），随后会出现登录屏幕。交换机也可以运行 DHCP 客户端，请检查 DHCP 服务器是否已分配其他 IP 地址。

![Swos login css106](/img/776fa0e1c75d6b6b.webp)

SwOS 默认 IP 地址：**192.168.88.1**，用户名：**admin**，并且没有密码。

[邻居发现](../../system-information-and-utilities/neighbor-discovery.md) 可用于发现 Mikrotik 交换机的 IP 地址。不支持 LLDP。

## 接口概览 {#interface-overview}

SwOS 接口菜单包含多个选项卡：Link、SFP、Forwarding、RST、Statistics、Errors、VLAN、VLANs、Hosts、IGMP Groups、SNMP、ACL、System 和 Upgrade。

SwOS 配置工具中按钮的说明：

- **Append** - 在列表末尾添加新项
- **Apply All** - 应用当前配置更改
- **Cut** - 从列表中删除一项
- **Clear** - 重置该项的属性
- **Discard Changes** - 移除未保存的配置
- **Insert** - 添加新项到列表（放在当前项之前）
- **Sort** - 按 VLAN ID 对 VLAN 表排序；按 MAC 地址对主机表排序
- **Change Password** - 更改交换机密码
- **Logout** - 从当前交换机注销
- **Reboot** - 重启交换机
- **Reset Configuration** - 将配置重置为出厂默认值
- **Choose File** - 浏览升级或备份文件
- **Upgrade** - 使用所选文件升级交换机固件
- **Download & Upgrade** - 自动尝试下载并升级固件，运行 Web 浏览器的 PC 应能访问互联网
- **Restore Backup** - 使用所选备份文件恢复交换机
- **Save Backup** - 从交换机生成并下载备份文件

> **注意：** 每个 RouterBOARD 交换机系列都有各自的固件，不能安装到其他系列型号上！CSS106-5G-1S（RB260GS）和 CSS106-1G-4P-1S（RB260GSP）支持 SwOS v2.0 及更高版本。升级设备时，它会先加载主固件，然后进行升级。如果选择了错误的固件文件，设备将继续使用主固件运行，你可以选择正确的文件。

## 系统 {#system}

System 选项卡执行以下功能：

- 交换机的一般信息
- 交换机管理
- 配置重置
- 备份和恢复配置

> **注意：** SwOS 使用简单算法来确保 TCP/IP 通信——它只回复数据包来源的同一 IP 和 MAC 地址。这样设备本身就不需要默认网关。

![Swos system1](/img/923e82d8459140b1.webp)

| 属性 | 描述 |
| --- | --- |
| **地址获取** | 指定要使用的地址获取方式：`DHCP with fallback` - 交换机尝试从 DHCP 服务器请求 IPv4 地址。如果请求不成功，则可以使用 **Static IP Address** 值访问交换机`static` - 地址设置为 **Static IP Address** 值（仅 IPv4）`DHCP only` - 交换机使用 DHCPv4 客户端获取地址 |
| **Static IP Address** | 当 **Address Acquisition** 设置为 `DHCP with fallback` 或 `static` 时，交换机的 IP 地址 |
| **Identity** | 交换机名称（用于 Mikrotik neighbor discovery protocol） |
| **Allow From** | 可访问交换机的 IP 地址或网络。默认值为 `0.0.0.0/0` - 任意地址。 |
| **Allow From Ports** | 可访问该服务的交换机端口列表 |
| **Allow From VLAN** | 可访问该服务的 VLAN ID。请确保先配置 VLAN 和 VLAN 页面 |
| **Watchdog** | 启用或禁用系统看门狗。发生故障情况时，它将重置交换机的 CPU |
| **Independent VLAN Lookup** | 启用或禁用主机表中的独立 VLAN 查找以进行数据包转发 |
| **IGMP Snooping** | 启用或禁用 IGMP Snooping |
| **IGMP Fast Leave** | 启用或禁用交换机端口上的 IGMP fast leave 功能。此属性仅在启用 IGMP Snooping 时生效 |
| **Mikrotik Discovery Protocol** | 启用或禁用 Mikrotik neighbor discovery protocol |
| **Port1 PoE In Long Cable** | 如果启用，它将关闭所有 PoE 输出端口上的短路检测，以允许使用更长的以太网线缆。这是一个潜在危险的设置，应谨慎使用。（CSS106-1G-4P-1S 型号） |
| **MAC Address** | 交换机的 MAC 地址（只读） |
| **Serial Number** | 交换机的序列号（只读） |
| **Board Name** | MikroTik 型号名称（只读） |
| **Voltage** | 显示以伏特为单位的输入电压（只读，CSS106-1G-4P-1S 型号） |
| **Temperature** | 显示摄氏度温标下的 PCB 温度（只读，CSS106-1G-4P-1S 型号） |

## 链路 {#link}

Link 选项卡允许你：

- 配置以太网和 SFP 端口
- 监控以太网和 SFP 端口状态

![Swos link css106](/img/04bcae8177929500.webp)

| 属性 | 描述 |
| --- | --- |
| **Enabled** | 启用或禁用端口 |
| **Name** | 可编辑的端口名称 |
| **Link Status** | 当前链路状态（只读） |
| **Auto Negotiation** | 启用或禁用自动协商（某些 SFP 模块可能需要禁用它才能工作） |
| **Speed** | 指定端口的速度设置（要求禁用自动协商） |
| **Full Duplex** | 指定端口的双工模式（要求禁用自动协商） |
| **Flow control** | 启用或禁用 802.3x 流控制 |

> **注意：** 使用 SFP+ 1m/3m DAC 电缆或 S-RJ01 模块时，即使另一端没有连接任何设备，设备也始终显示链路已建立。

交换机支持最大 9198 bytes 的 Jumbo 帧。SwOS 设备不支持手动降低 MTU 设置。

### PoE {#poe}

PoE 设置会更改 CSS106-1G-4P-1S port2-port5 上的 Power over Ethernet 输出，并显示 PoE 状态和测量值。

![740px Swospoe2](/img/edfe6029282de3b7.webp)

| 属性 | 描述 |
| --- | --- |
| **PoE Out** | 设置端口的 PoE 输出模式：`off` - 关闭所有检测和 PoE 输出；`auto` - 根据备用线对上的电阻进行检测，以检查端口是否具有 PoE 能力。要使端口开启，测量值应在 3kΩ 到 26.5kΩ 范围内；`on` - 无论端口上的电阻如何，都会启用 PoE 输出。***请谨慎使用，因为这可能损坏连接的设备！***；`calibr` - 手动重新校准端口 PoE 输出。如果为连接设备供电时偶尔出现问题，可能需要执行此操作。 |
| **PoE Priority** | PoE 输出供电的端口优先级。如果安装超出可用功率预算，优先级最低的端口将首先关闭。`1` - 优先级最高的端口；`4` - 优先级最低的端口 |
| **PoE Status** | 端口当前的 PoE 输出状态：`disabled` - PoE 输出已关闭；`waiting for load` - `auto` 模式检测到超出范围的电阻以开启 PoE 输出；`powered on` - PoE 输出已开启；`short circuit` - 如果检测到短路，则关闭 PoE 输出，以确保受电设备不会受到额外损坏，供电设备也不会损坏；`voltage too low` - 提供的电压不足以通过 PoE 输出开启设备；`current too low` - 提供的电流不足以通过 PoE 输出开启设备；`waiting for cable disconnect` - 使用 `calibr` 进行手动重新校准已检测到连接的设备，并等待断开连接以完成重新校准过程 |
| **PoE Current** | 显示端口上的电流使用量，单位为 milliamperes |
| **PoE Power** | 显示端口上的 PoE 输出功率，单位为 watts |

## 转发 {#forwarding}

Forwarding 选项卡提供交换机端口之间的高级转发选项、端口隔离、端口锁定、端口镜像和出方向带宽限制功能。通过设置 `Rate`，可以使用[访问控制列表](#acl)配置每个端口的入方向速率和广播流量速率。ACL 必须为每个条目设置一个端口，才能正确提供带宽限制。

![740px Swos forwarding2](/img/ca2d7131f8465cde.webp)

| 属性 | 描述 |
| --- | --- |
| **Forwarding** | 转发表 - 允许或限制特定端口之间的流量 |
| **Port Lock** | `Port Lock` - 启用或禁用此端口上的 MAC 地址学习。启用该选项后，将限制 MAC 地址学习，应配置静态 MAC 地址；`Lock On First` - 启用或禁用此端口上的 MAC 地址学习（仍会学习第一个接收数据包的 MAC 地址） |
| **Port Mirroring** | `Mirror Ingress` - 进入此端口的流量是否必须复制并转发到镜像目标端口；`Mirror Egress` - 离开此端口的流量是否必须复制并转发到镜像目标端口；`Mirror To` - 镜像目标端口 |
| **Bandwidth Limit** | `Egress Rate` - 限制离开此端口的流量（bps） |

## RSTP {#rstp}

RSTP 菜单中提供每端口和全局 RSTP 配置与监控。

![Swos RSTP css106](/img/001984d0b4ba3e55.webp)

| 属性 | 描述 |
| --- | --- |
| **RSTP** | 启用或禁用该端口上的 STP/RSTP 功能 |
| **模式** | 显示特定端口上的 STP/RSTP 功能模式（只读）：`RSTP``STP` |
| **角色** | 显示特定端口角色（只读）：`root` - 朝向根网桥并将用于向根网桥转发流量或从根网桥转发流量的端口`alternate` - 朝向根网桥但不转发流量的端口（根端口的备份）`backup` - 背向根网桥但不转发流量的端口（非根端口的备份）`designated` - 背向根网桥并会转发流量的端口`disabled` - 严格来说不属于 STP 的端口（RSTP 功能已禁用） |
| **根路径开销** | 显示朝向根网桥的端口的根路径开销（只读） |
| **Type** | `edge` - 不应接收任何 BPDU 的端口，应连接到终端站（只读）；`point-to-point` - 在全双工链路上运行的端口，可以是 STP 的一部分并处于转发状态（只读） |
| **State** | 显示每个端口状态（只读）：`forwarding` - 端口参与流量转发并学习 MAC 地址，正在接收 BPDU；`discarding` - 端口不参与流量转发且不学习 MAC 地址，正在接收 BPDU；`learning` - 端口不参与流量转发，但正在学习 MAC 地址 |
| **网桥优先级（十六进制）** | 用于根网桥选择的 RSTP 网桥优先级 |
| **Port Cost Mode** | 根据链路速度自动检测 RSTP 端口开销有两种方法。`short`：10G - 2；1G - 4；100M - 10；10M - 100；`long`：10G - 2000；1G - 20000；100M - 200000；10M - 2000000 |
| **转发保留组播** | 是否转发 **01:80:C2:00:00:0x** 范围内的 IEEE 保留组播 MAC 地址。符合 R/M/STP 标准的交换机应避免转发这些数据包。如果启用此设置，SwOS 将转发保留组播 MAC 数据包并禁用 RSTP：- 交换机将不处理传入的 BPDU（桥接协议数据单元）- 它也不会发送自己的 BPDU- 网桥优先级和按端口的 RSTP 配置设置将不再有任何效果。启用保留 MAC 地址的转发可能影响依赖这些地址的某些协议。建议仅在绝对必要时才启用转发，例如在透明桥接配置中（例如延长长距离链路、将网桥用作介质转换器或进行网络分析）。值得注意的 MAC 地址和协议示例（RouterOS 使用的）：`01:80:C2:00:00:00` - 生成树协议（STP）`01:80:C2:00:00:01` - 以太网流控`01:80:C2:00:00:02` - 链路聚合控制协议（LACP）`01:80:C2:00:00:03` - Dot1x 客户端和服务器`01:80:C2:00:00:08` - 生成树协议（用于 802.1ad 网桥，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0D` - 多 VLAN 注册协议（用于 802.1ad 网桥，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0E` - 链路层发现协议、多机箱链路聚合组和精确时间协议流控 MAC 地址 `01:80:C2:00:00:01` 是一个例外 —— 它不会被 SwOS 转发。 |
| **根网桥** | 网络中所选根网桥的优先级和 MAC 地址（只读） |

## VLAN 与 VLANs {#vlan-and-vlans}

交换机端口的 VLAN 配置。

![740px Swos vlan2](/img/5d51b5ec225f57e1.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN Mode** | 入方向端口的 VLAN 模式：`disabled` - 不使用 VLAN 表；交换机忽略带标签数据包的 VLAN 标签部分；`optional` - 对于 VLAN 标签 ID 不在 VLAN 表中的数据包，就像没有 VLAN 标签的数据包一样处理；`enabled` - 丢弃 VLAN 标签 ID 不在 VLAN 表中的数据包。没有 VLAN 标签的数据包会被视为带有 `Default VLAN ID` 的带标签数据包；`strict` - 与 `enabled` 相同，但还会检查入站接口的 VLAN 支持（丢弃 VLAN 标签 ID 和入方向端口不在 VLAN 表中的数据包） |
| **VLAN Receive** | 定义入方向端口上允许的数据包类型：`any` - 允许某个端口上的带标签和不带标签数据包；`only tagged` - 仅允许带有 VLAN 标签的数据包；`only untagged` - 仅允许不带 VLAN 标签的数据包 |
| **Default VLAN ID** | 交换机将把不带标签的入方向数据包和带有 "Default VLAN ID" 标签的入方向数据包都视为带有此 VLAN ID 的标签。如果数据包的 VLAN ID 与 "Default VLAN ID" 匹配，它也会用于移除出方向流量的标签。只有在出方向端口指定了 `VLAN Header = add if missing` 时，才会添加 VLAN 标签本身 |
| **Force VLAN ID** | 是否将 `Default VLAN ID` 应用于带有 VLAN 标签的传入数据包 |
| **VLAN Header** | `leave as is` - 如果存在 VLAN 头，则保持不变；`always strip` - 如果存在 VLAN 头，则从数据包中移除；`add if missing` - 如果不存在 VLAN 头，则将其添加到数据包中（VLAN ID 将为入方向端口的 `Default VLAN ID`） |

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤（VLAN Mode 为 **enabled** 或 **strict**）时可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13 版本，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

> **注意：** VLAN 模式 `enabled` 和 `strict` 要求 VLANs 表中存在 VLAN ID 1，以允许不带标签的流量访问交换机本身。

VLAN 表指定具有 IEEE 802.1Q 标签的数据包的转发规则。基本上，该表包含将特定 VLAN 标签 ID 映射到一个或多个端口组的条目。带有 VLAN 标签的数据包通过相应表项中设置的一个或多个端口离开交换机。VLAN 表与目标 MAC 查找一起工作，以确定出方向端口。VLAN 表最多支持 250 个条目。

![Swos vlan css106](/img/cdfe40f140124a72.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN ID** | 数据包的 VLAN ID |
| **IVL** | 启用或禁用独立 VLAN 学习（IVL） |
| **IGMP Snooping** | 启用或禁用已定义 VLAN 上的 IGMP Snooping。启用后，交换机将监听来自已定义 VLAN 的 IGMP Join 和 Leave 请求，并且仅将流量转发到已从该 VLAN 发送 IGMP 成员请求的端口。禁用后，交换机将向所有 VLAN 成员端口泛洪组播流量。 |
| **Ports** | 每个端口针对每个 VLAN ID 都有单独的 *VLAN header* 选项。取决于 *VLAN mode*，如果在此表中进行查找，则数据包的出方向动作由此选项处理。**VLAN tab** 中的出方向选项将被忽略。 |

### VLAN 配置示例 {#vlan-configuration-examples}

#### Trunk 和 Access 端口 {#trunk-and-access-ports}

![Access ports small](/img/d235e6fd5caac3d6.webp)

1. 在 System 菜单中启用独立 VLAN 学习（IVL）。

![Css106 ivl](/img/69cce788e8633553.webp)

1. 在 VLANs 菜单中添加 VLAN 条目，指定端口成员关系，并启用 IVL。可以使用默认的 "leave as is" 端口设置；可以通过 "Default VLAN ID" 设置更改打标签和移除标签的行为，请参见下一步。

![Css access trunk vlans](/img/866c15add91965c4.webp)

1. 在 VLAN 菜单中，在计划的 access 端口（不带标签）上配置 Default VLAN ID，选择正确的 VLAN Receive 设置（Port2 为 only tagged，Port3-5 为 only untagged），并启用严格的 VLAN 过滤，以确保只有允许的 VLAN 可以通过这些端口。

![Css106 access vlan](/img/894c635777800fe4.webp)

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤（VLAN Mode 为 **enabled** 或 **strict**）时可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13 版本，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

#### Trunk 和 Hybrid 端口 {#trunk-and-hybrid-ports}

![Hybrid ports small](/img/238fa201dac1535f.webp)

1. 在 System 菜单中启用独立 VLAN 学习（IVL）。

![Css106 ivl 1](/img/69cce788e8633553.webp)

1. 在 VLANs 菜单中添加 VLAN 条目，指定端口成员关系，并启用 IVL。可以使用默认的 "leave as is" 端口设置；可以通过 "Default VLAN ID" 设置更改打标签和移除标签的行为，请参见下一步。

![Css hybrid vlan](/img/05a39054ed03bffb.webp)

1. 在 VLAN 菜单中，在计划的 hybrid 端口（用于不带标签的 VLAN）上配置 Default VLAN ID，选择正确的 VLAN Receive 设置（Port2 为 only tagged，Port3-5 为 any），并启用严格的 VLAN 过滤，以确保只有允许的 VLAN 可以通过这些端口。

![Css hybrid vlans](/img/b285dc0d4f377d42.webp)

> **注意：** 运行 SwOS 2.12 版本的 CSS106 设备在端口上启用 VLAN 过滤（VLAN Mode 为 **enabled** 或 **strict**）时可以过滤 RSTP BPDU 数据包。对于 SwOS 2.13 版本，建议在 trunk 端口上将 VLAN Receive 设置为 **any**。

#### 管理访问 {#management-access}

在此示例中，将创建 VLAN 200 上的交换机管理访问。配置方案与 "**Trunk 和 Access 端口**" 相同，步骤 **1.、2.、3.** 完全相同。额外的 **第 4** 步需要在 System 菜单中指定管理 VLAN ID。应用配置后，交换机将仅在 Port2 上响应带标签的 VLAN 200 数据包，并在 Port3 上响应不带标签的数据包。DHCP 客户端也将在指定的 VLAN ID 中工作。

![Css106 system vlan](/img/ebd3dc6d62accb2d.webp)

> **警告：** 如果 VLAN 设置配置不正确，更改管理 VLAN 可能会完全禁用对交换机管理的访问。更改此设置之前，请保存配置备份，并在管理访问丢失时使用[重置](#reset)。

## 主机 {#hosts}

此表表示动态学习到的 MAC 地址到端口映射条目。它可以包含两种条目：动态和静态。动态条目会自动添加——这也称为学习过程：当交换机从某个端口接收到数据包时，它会将该数据包的源 MAC 地址 X 以及接收到该数据包的端口添加到主机表中，因此当带有目标 MAC 地址 X 的数据包进入时，它就知道应该将数据包转发到哪个端口。如果目标 MAC 地址不在主机表中，则它会将数据包转发到组中的所有端口（泛洪）。动态条目大约需要 5 分钟超时。

CSS106 系列交换机支持 2048 个主机表条目。

![Swos hosts css106](/img/a579ada46273a14f.webp)

| 属性 | 描述 |
| --- | --- |
| **Port** | 数据包应转发到的端口（只读） |
| **MAC** | 学习到的 MAC 地址（只读） |
| **VLAN ID** | 学习到的 VLAN ID（只读） |

### 静态主机 {#static-hosts}

如果已存在具有相同 MAC 地址的动态条目，静态条目将取代动态条目。添加静态条目还可以访问附加功能。

![740px Swos static2](/img/b02ac39742098a2b.webp)

| 属性 | 描述 |
| --- | --- |
| **Ports** | 数据包应转发到的端口 |
| **MAC** | MAC 地址 |
| **VLAN ID** | VLAN ID |
| **Drop** | 来自某些端口的具有特定 MAC 地址的数据包可以被丢弃 |
| **Mirror** | 数据包可以被克隆并发送到镜像目标端口 |

首先，在 System 选项卡下启用该选项。

## SNMP {#snmp}

SwOS 支持 SNMP v1 和 v2c（对 GetRequest、GetNextRequest 和 GetBulkRequest 的响应），并使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（仅用于 health、PoE-out 和 SFP 诊断）。不支持 SNMP trap 和写入 SwOS 配置。

可用的 SNMP 数据：

- 系统信息
- 系统运行时间
- 端口状态
- 接口统计
- 主机表信息

![Swos snmp2](/img/f3b87569bbcad587.webp)

| 属性 | 描述 |
| --- | --- |
| **Enabled** | 启用或禁用 SNMP 服务 |
| **Community** | SNMP 团体名称 |
| **Contact Info** | NMS 的联系信息 |
| **Location** | NMS 的位置信息 |

## ACL {#acl}

访问控制列表 (ACL) 规则表是一个非常强大的工具，可根据 L2、L3 和 L4 协议头字段条件进行线速数据包过滤、转发和 VLAN 打标签。SwOS 允许你实施有限数量的访问控制列表规则（32 条仅使用 L2 条件的简单规则；16 条同时使用 L2 和 L3 条件的规则；或 8 条使用所有 L2、L3 和 L4 条件的高级规则）。每条规则包含条件部分和动作部分。

![740px Swos acl2](/img/0bd3d4c1437ed824.webp)

**条件参数**

| 属性 | 描述 |
| --- | --- |
| **From** | 数据包进入的端口 |
| **MAC Src** | 源 MAC 地址和掩码 |
| **MAC Dst** | 目标 MAC 地址和掩码 |
| **Ethertype** | 封装在以太网帧有效载荷中的协议 |
| **VLAN** | VLAN 头是否存在：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 标签 ID |
| **Priority** | VLAN 标签中的优先级 |
| **IP Src** (IP/netmask:port) | 源 IPv4 地址、网络掩码和 L4 端口号 |
| **IP Dst** (IP/netmask:port) | 目标 IPv4 地址、网络掩码和 L4 端口号 |
| **Protocol** | IP 协议 |
| **DSCP** | IP DSCP 字段 |

**动作参数**

| 属性 | 描述 |
| --- | --- |
| **Redirect To** | 是否强制使用新的目标端口（如果启用了 "Redirect To"，但未在 "Redirect To Ports" 中指定端口，则数据包将被丢弃） |
| **Redirect To Ports** | 重定向目标端口 |
| **Mirror** | 克隆数据包并将其发送到镜像目标端口 |
| **Rate** | 限制带宽（bps） |
| **Set VLAN ID** | 如果存在 VLAN 标签，则更改 VLAN 标签 ID |
| **Priority** | 如果存在 VLAN 标签，则更改 VLAN 标签优先级位 |

## 重置 {#reset}

CSS106-5G-1S 和 CSS106-1G-4P-1S 内置备份 SwOS 固件，可在标准固件损坏或升级失败时加载：

- 在设备启动时按住 Reset 按钮几秒钟将重置配置并加载备份固件。
- 加载备份固件后，可以使用 Web 浏览器连接到 192.168.88.1（或从 DHCP 服务器租用的地址）并安装新的 SwOS 固件。
