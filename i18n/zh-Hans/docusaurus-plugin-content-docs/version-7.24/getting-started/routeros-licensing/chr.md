Cloud Hosted Router（CHR）是 RouterOS 的虚拟化版本，设计用于在 x86_64 虚拟环境中运行。它提供与 MikroTik 硬件设备相同的核心路由、防火墙、VPN 和管理功能。

本节介绍 CHR 安装、部署和授权。
