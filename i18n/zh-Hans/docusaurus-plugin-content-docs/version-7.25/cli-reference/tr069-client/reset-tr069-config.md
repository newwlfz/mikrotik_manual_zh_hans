## tr069-client/reset-tr069-config {#tr069-clientreset-tr069-config}
**包：** tr069-client
**类型：** 命令

该命令会完全重置并清除 tr069-client 的配置和状态（不影响其他 RouterOS 配置）。当 CWMP 进入无响应或挂起状态，需要在无需重新安装 RouterOS 的情况下进行恢复时，请使用此命令。
