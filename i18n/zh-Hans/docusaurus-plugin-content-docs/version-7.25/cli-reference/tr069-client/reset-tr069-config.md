## tr069-client/reset-tr069-config 
**Package：** tr069-client
**Type：** Command

该命令会完全重置并清除 tr069-client 配置和状态（不影响其他 RouterOS 配置）。当 CWMP 进入无响应或挂起状态，且需要在不重新安装 RouterOS 的情况下恢复时，使用该命令。
