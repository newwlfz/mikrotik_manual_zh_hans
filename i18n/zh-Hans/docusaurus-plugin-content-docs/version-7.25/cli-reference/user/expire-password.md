## user/expire-password 
**类型：** 命令

使所选用户的密码过期（在 [`/user`](/docs/cli-reference/user) 中设置 `E` 标志）。下次交互式登录时，系统会要求用户设置新密码；使用 `/user/set` 设置新密码也会清除该标志。完整指南请参阅 [User](/docs/authentication-authorization-accounting/user)。
