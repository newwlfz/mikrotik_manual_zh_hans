## ip/proxy/clear-cache 
**类型：** 命令

删除 Web Proxy 缓存中的所有对象。更改 [`/ip/proxy`](/docs/cli-reference/ip/proxy) 中的任何设置也会清除缓存。有关缓存的概述，请参阅 [Web Proxy](/docs/network-management/proxy/web-proxy)。
