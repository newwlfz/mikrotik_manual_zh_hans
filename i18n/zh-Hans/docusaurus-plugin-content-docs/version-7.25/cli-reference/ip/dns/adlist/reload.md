## ip/dns/adlist/reload {#ipdnsadlistreload}
**类型：** 命令

立即检查所有 adlist 是否有更新，而不是等到下一次 4 小时检查时再进行，并且只应用发生变更的部分。如果某个列表的导入因缓存过小而停止，此命令不会将其补全。
