## system/ntp/client/reset-freq-drift 
**类型：** 命令

将客户端测得的本地时钟频率漂移重置为零，丢弃客户端已学习到的校正值。客户端继续轮询其服务器时，将重新建立估算值。请参阅 [NTP](/docs/system-information-and-utilities/ntp) 指南。
