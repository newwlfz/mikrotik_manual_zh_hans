本节将介绍 802.11 无线协议的配置以及最佳使用示例。

路由器的无线能力可以极大地提升家庭或办公网络的可用性，也能为工业场景提供解决方案。对于缺乏经验的用户来说，挑选合适的设备进行配置可能是个难题。本指南旨在解释各种参数，并给出一种思路，帮助你在种类繁多的 MikroTik 路由器中不至于迷失方向。

### 哪个章节适合我的设备？ {#which-section-is-for-my-device}

MikroTik 无线设备分为多个产品系列，每个系列都通过特定的 RouterOS 菜单进行配置。在下面找到你的设备，然后跳转到对应章节：

| 产品系列 | RouterOS 菜单 | 驱动程序包 |
| :-- | :-- | :-- |
| [Wi-Fi 6 / 7 (802.11 ax/be)](./wifi/index.md) | `/interface/wifi` | `wifi-qcom`, `wifi-qcom-be`, `wifi-mediatek` |
| [Wi-Fi 5 (802.11ac)](./wifi-ac/index.md) | `/interface/wifi` *或* `/interface/wireless` | `wifi-qcom-ac` *或* `wireless` |
| [802.11 a/b/g/n](./abgn/index.md) | `/interface/wireless` | `wireless` |
| [60 GHz (W60G)](./w60g/index.md) | `/interface/w60g` *或* `/interface/wifi` | `wireless` |

802.11ac 设备是唯一可以二选一使用哪种菜单的设备 —— [Wi-Fi 5 (802.11ac)](./wifi-ac/index.md) 章节说明了如何选择。下面的软件包对照表更详细地涵盖了这一选择。

:::tip[不确定你的设备属于哪个系列？]
无线标准通常会体现在型号名称中。例如，**wAP ax** 和 **hAP ax³** 是 802.11ax（Wi-Fi 6），**hAP be lite** 是 802.11be（Wi-Fi 7），**hAP ac²** 和 **wAP ac** 是 802.11ac（Wi-Fi 5），而 Cube **60Pro** 是 60 GHz（W60G）设备。
:::

### RouterOS 软件包类型 {#routeros-package-type}

部分 MikroTik 设备可以在两种无线 NPK 软件包（即无线驱动程序）之间进行选择，具体取决于所需功能和设备类型。更多细节可在各自的文档章节中找到。无论 CPU 架构如何、也无论使用哪种无线驱动程序，CAPsMAN 功能都包含在 routeros 捆绑包中，也就是说你可以在任何型号上运行 CAPsMAN。

简而言之：

- CAPsMAN 可以运行在任何 MikroTik 设备上。大多数情况下，你可以同时运行新版和旧版 CAPsMAN（在 AX 路由器上同时运行两者时，无法使用内置网卡）。
- MIPS 类型设备没有驱动程序可选，仅支持旧版驱动程序。
- ARM CPU 的 802.11AC 无线设备可以选择无线驱动程序：wireless.npk 或 wifi-qcom-ac.npk。

下面的表格可以帮助你在这种情况下做出选择：

### 频段 {#frequencies}

MikroTik 提供的路由器接口涵盖 3 个频段 —— 2.4GHz、5GHz 和 60GHz。每个频段都有自己的优势和适用场景。

#### 2.4GHz {#24ghz}

如今由于过度使用而被视为旧技术，但它仍是支持最广泛的频段。如果你有手机、笔记本电脑或其他设备这样的无线客户端，它极有可能支持该频段。甚至 IoT 设备也常常支持 2.4GHz 频段。由于频率较低，2.4GHz 频段能更好地克服障碍物，因此相比 5GHz 设备具有更大的覆盖范围，但通常吞吐量（上网速度）也更小。此外，它可能会因其他 2.4GHz 无线设备的干扰（噪声）而受到严重影响，因为几乎每个家庭接入点都支持 2.4GHz 频段，而且它在穿墙和长距离传输方面表现良好；同时可选频率也更少（3 个非重叠信道）。如果你周围有很多近距离的邻居（公寓、共享办公楼），那么 2.4GHz 频段很可能已经饱和，性能会下降。该频段也可用于工业链路。

#### 5GHz {#5ghz}

通常，新款的手机和笔记本电脑也支持 5GHz 频段。如果你的客户端设备和路由器支持 802.11ac（有时简称为 "ac"），那么它比 2.4GHz 频段更快。5GHz 频段有更多可选频率，但覆盖范围通常比 2.4GHz 频段更小。如果你有新的客户端设备，ac 路由器将让你的网络受益。由于频率范围大，5GHz 频段也常用于工业链路。

#### 60GHz {#60ghz}

目前，支持 60GHz 频段的客户端设备（手机、笔记本电脑）非常少。不过，它为工业链路提供了前沿的解决方案。例如，如果你有两个点需要连接，距离最远可达 1500 米，你将获得 1 Gbps 的双向链路。例如，MikroTik 有一款产品名为 *Wireless Wire*，因为它能提供与 1Gbps 有线连接相同的速度，但你需要无遮挡的视距才能建立链路。

### 使用场景 {#use-case}

MikroTik 设备上的 RouterOS 软件提供了广泛而连贯的配置可能性。RouterOS 软件让你能以多种方式使用 MikroTik 设备，例如，如有需要，"家庭接入点"设备可以很容易地重新配置为客户端或组成点对点链路。所谓"家庭 AP"只是默认配置，你可以将其更改为任何你想要的配置。话虽如此，最好还是按照硬件的设计用途来使用它。

#### 用于手机和笔记本电脑的家庭 AP {#home-ap-for-phones-and-laptops}

在确定最适合你的方案之前，你应该回答这样一些问题：你想连接多少个客户端、需要覆盖多大范围、想获得多高的速度。

#### 客户端数量 {#client-count}

连接的客户端越多，延迟越高、吞吐量越小。为达到最佳性能，我们建议每个接口连接 20-50 个客户端；视条件不同，客户端数量可以增加到 100 个并仍保持稳定运行。如果客户端需要高吞吐量，或数据流量对时延敏感，建议每个接入点规划更少的客户端。通常，选择更简单的接入点但更密集地部署它们会更有益。

#### 覆盖范围 {#range}

无线连接的覆盖范围取决于许多条件，其中包括天线增益、路由器和客户端设备的发射功率、来自其他设备的干扰、障碍物（墙壁、金属物体）以及路由器的摆放位置。需要注意的一个重要因素是，所有参与的设备都会影响可达到的距离，这意味着无论你的 AP 多么强大和灵敏，小手机都会受限于自身的发射功率和灵敏度。如果客户端设备是手机，单个设备无法覆盖较大区域。通常只能达到几百米，要覆盖更大的区域就需要更多的 AP 设备。

- **天线增益** 以 dBi 为单位衡量，它决定了波束有多窄。0 dBi（实际上不可能）的辐射方向图呈球形，1.5 dBi - 5 dBi 几乎向所有方向辐射，但会有一些凹陷，某些方向信号会更强。> 9 dBi 具有明显的定向辐射方向图。天线增益更高的天线如果摆放得当，就能在所需方向上覆盖更远。
- **发射功率** 以 dBm 或 mW 为单位衡量，它决定了无线接口发出的信号强度。移动设备通常发射功率较低，以节省电量。举例来说，即使手机报告接收信号强度良好，路由器从手机接收到的信号也可能很弱。

- 来自其他设备的 **干扰** 会抬高噪声底，路由器就更难从噪声中分辨出信号，因此信号必须更强，客户端必须离接入点更近。同一频率上的接入点占用相同的空口时间，从而降低吞吐量并增加延迟。

- 一些 **物体** 会降低（衰减）信号强度，另一些则会反射信号。在建筑物中，通常必须考虑墙壁及其厚度、地板和天花板、金属物体。玻璃和木材也会衰减信号。

- 接入点的 **摆放位置** 也会影响覆盖范围。接入点不应被金属物体或表面遮挡，这样信号才有空间传播。

#### 速度 {#speed}

如果速度很重要，那么你应该选择支持 802.11 ac 的 5GHz 无线路由器。

### 用于连接其他无线天线（CPE 到 AP） {#for-other-wireless-antennas-to-connect-cpe-to-ap}

通常需要连接两个或多个点，例如连接园区内的建筑、将客户端家庭接入网络，或建立长距离链路。MikroTik 在这些场景下同样提供了解决方案。为了做出选择，你必须了解距离、需要连接的是两个点（点对点 - PtP）还是多个点（点对多点 - PtMP），以及你需要什么速度。

#### 距离 {#distance}

由于在这些场景中我们面对的是定向天线和远距离，你必须牢记对准和无遮挡视距至关重要。对于最远 1500 米的小距离，我们建议使用 60 GHz 设备，它能提供稳定性和出色的速度。此外，在短距离下，天线增益较小的 2.4 GHz 或 5 GHz 设备也完全够用，尽管你无法获得 60 GHz 设备那样的速度。对于更长的链路，则应考虑天线增益和发射功率。更高的信号强度可实现更高的数据速率，也就意味着更高的吞吐量。明智地选择频率，以避免与其他无线链路产生干扰。请记住，在城市中即便在屋顶之上，也常常存在来自邻近 2.4 GHz 和 5 GHz 链路的干扰。

#### PtP 还是 PtMP {#ptp-or-ptmp}

PtP 和 PtMP 链路在某些方面有所不同。对于 PtMP，你可能需要一个波束更宽的天线，也就是所谓扇形天线。这种天线覆盖角度更宽，但增益更低，因此距离更短。此外，在 PtMP 中，接入点必须至少具有 4 级 RouterOS 软件许可。连接到接入点的客户端或设备以及 PtP 链路中的设备可以具有 3 级许可和更窄的波束宽度。

#### 速度 {#speed-1}

对于短链路中的更高速度，你必须选择 60 GHz 设备；对于更长的距离，则选择 5GHz ac 设备。

#### 注意 {#note}

要控制大型接入点网络，你可以使用 CAPsMAN —— 一个能从单一位置为众多接入点进行配置的控制器。请使用与你的设备菜单相匹配的控制器：对于 `/interface/wifi` 设备（`wifi-qcom` / `wifi-qcom-ac`），使用 [WiFi CAPsMAN](./wifi/capsman.md)；对于旧版 `/interface/wireless` 设备，使用 [CAPsMAN](./abgn/capsman/index.md)。要控制数百个接入点，我们建议使用我们的 CCR 系列设备。要控制数千个接入点，你或许可以尝试使用 CHR 或 x86 机器。
