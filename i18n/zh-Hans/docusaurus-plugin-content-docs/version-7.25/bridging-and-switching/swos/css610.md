## 摘要 {#summary}

SwOS Lite 是专为管理 MikroTik CSS610 系列交换机产品而设计的操作系统。CSS610 系列交换机仅支持 SwOS Lite 操作系统。

与 CSS3xx 系列交换机相比的主要差异如下：

- 不支持 Independent VLAN Learning
- 不支持 VLAN 模式“enabled”
- 不支持 ACL 速率限制
- 支持端口出口速率限制

## 连接到交换机 {#connecting-to-the-switch}

打开 Web 浏览器并输入交换机的 IP 地址（默认为 192.168.88.1），将显示登录界面。交换机也可以运行 DHCP 客户端，请检查 DHCP 服务器是否分配了其他 IP 地址。

![Swos login css610](/img/388461ec86ffddb8.webp)

SwOS 默认 IP 地址：**192.168.88.1**，用户名：**admin**，无密码。

[MikroTik Neighbor Discovery](/docs/7.24/system-information-and-utilities/neighbor-discovery) 可用于发现 MikroTik 交换机的 IP 地址。不支持 LLDP。

## 接口概述 {#interface-overview}

SwOS 接口菜单由多个选项卡组成，具体取决于设备型号。以下是所有可能的 SwOS 菜单：Link、PoE、SFP、Port Isolation、LAG、Forwarding、RSTP、Stats、Errors、Hist、VLAN、VLANs、Hosts、IGMP、SNMP、ACL、System、Health 和 Upgrade。

SwOS 配置工具中的按钮说明：

- **Append** - 在列表末尾添加新项目
- **Apply All** - 应用当前配置更改
- **Cut** - 从列表中移除项目
- **Clear** - 重置项目属性
- **Discard Changes** - 移除未保存的配置
- **Insert** - 向列表添加新项目（将其放在当前项目之前）
- **Sort** - 按 VLAN-ID 对 VLAN 表排序；按 MAC 地址对主机表排序
- **Change Password** - 更改交换机密码
- **Logout** - 退出当前交换机
- **Reboot** - 重启交换机
- **Reset Configuration** - 将配置重置为出厂默认值
- **Choose File** - 浏览升级或备份文件
- **Upgrade** - 使用所选文件升级交换机固件
- **Download & Upgrade** - 自动尝试下载并升级固件，运行 Web 浏览器的 PC 应能访问 Internet
- **Restore Backup** - 使用所选备份文件恢复交换机
- **Save Backup** - 从交换机生成并下载备份文件

> **说明：** 每个 RouterBoard 交换机系列设备都有其专用固件，无法安装在其他系列型号上！
>
> - CSS610-1Gi-7R-2S+ 支持 SwOS Lite v2.12 及更高版本。
> - CSS610-8G-2S+ 支持 SwOS Lite v2.12 及更高版本。
> - CSS610-8P-2S+IN 支持 SwOS Lite v2.15 及更高版本。

## 端口隔离 {#port-isolation}

Port Isolation 表允许或限制特定端口之间的流量转发。默认情况下，所有可用的交换芯片端口都可以与任何其他端口通信——未使用隔离。启用或勾选复选框后，允许流量从此端口转发到已勾选的端口。以下是一些端口隔离示例。

![SwOS Isolated Groups](/img/284614f24611b0f4.webp)

在某些情况下，您可能需要将一组设备与其他组隔离。在本示例中，**Port1-Port5** 上的设备无法与 **Port6-Port10** 上的设备通信，反之亦然。

![SwOS Private VLAN](/img/606fbb63c2620b62.webp)

在某些情况下，您可能需要将所有流量转发到上行端口，同时所有其他端口彼此隔离。这种配置称为 **Private VLAN** 配置。交换机只会将所有以太网帧转发到上行 **Port1**，而上行端口可以访问所有其他端口。

![SwO isolation example3](/img/de28135343d9795b.webp)

单个隔离的 **Port1**（例如用于管理目的）——它无法从任何其他端口发送或接收流量。

> **注意：** 可以通过勾选其中一个复选框然后水平拖动来勾选/取消勾选多个复选框（Click & Drag）。

> **注意：** (R)STP 仅在 Private VLAN 配置中才能正常工作。在具有多个隔离交换机组的配置中，(R)STP 可能无法正确接收 BPDU，因此无法检测网络环路。

## LAG

支持兼容 IEEE 802.3ad (LACP) 的链路聚合，以及静态链路聚合，以确保基于 Layer2 哈希的故障转移和负载均衡。最多支持 16 个链路聚合组，每组最多 8 个端口。每个单独端口可以配置为 Passive LACP、Active LACP 或 Static LAG 端口。

| 属性 | 说明 |
| --- | --- |
| **Mode** *(default: passive)* | 指定端口上的 LACP 数据包交换模式或 Static LAG 模式：<br/><code>Passive</code> - 将端口置于侦听状态，仅当对端端口使用 active LACP 模式时才使用 LACP<br/><code>Active</code> - 无论对端端口模式如何，都优先启动 LACP<br/><code>Static</code> - 将端口设置为 Static LAG 模式；需要为所有需要包含在同一静态 LAG 中的端口设置相同的 <strong>Group</strong> 设置 |
| **Group** | 指定 Static LAG 组 |
| **Trunk** *(read-only)* | 表示端口所属的组编号 |
| **Partner** *(read-only)* | 表示对端 MAC 地址；仅在端口包含在 LACP 中时可用 |

## Forwarding

Forwarding Tab 提供交换机端口之间的高级转发选项、端口锁定、端口镜像、带宽限制和广播风暴控制功能。

![Swos forw css610](/img/41fc3bd40fd23388.webp)

| 属性 | 说明 |
| --- | --- |
| **Port Lock** | <code>Port Lock</code> - 启用或禁用该端口上的 MAC 地址学习。启用该选项时，将限制 MAC 地址学习，应配置静态 MAC 地址。任何源 MAC 地址未知的已接收帧都将被丢弃<br/><code>Lock On First</code> - 允许从接收到的第一个帧学习源 MAC 地址；该属性应与 <code>Port Lock</code> 一起使用。每次接口状态变化时，第一个 MAC 地址的学习都会重置 |
| **Port Mirroring** | <code>Mirror Ingress</code> - 进入该端口的流量是否必须被复制并转发到镜像目标端口<br/><code>Mirror Egress</code> - 离开该端口的流量是否必须被复制并转发到镜像目标端口<br/><code>Mirror To</code> - 镜像目标端口 |
| **Broadcast Storm Control** | <code>Storm Rate</code> - 限制接口发送的广播数据包数量。速率以比特每秒（bps）为单位<br/><code>Include Unknown Unicast</code> - 将主机表中没有条目的单播数据包纳入 <code>Storm Rate</code> 限制 |
| **Multicast Flood Control** | `Flood Unknown Multicast` - 更改交换机端口上的组播泛洪选项；仅控制出站流量。启用时，网桥允许将组播数据包泛洪到指定交换机端口；禁用时，限制组播流量被泛洪。该设置影响所有组播流量，包括非 IP、IPv4、IPv6 和链路本地组播范围（例如 224.0.0.0/24 和 ff02::1） |
| **Bandwidth Limit** | <code>Ingress Rate</code> - 限制进入该端口的流量（bps）<br/><code>Egress Rate</code> - 限制离开该端口的流量（bps） |

> **注意：** 可以按端口限制 ingress/egress 流量。ingress 流量使用 policer，egress 流量使用 shaper。ingress policer 通过丢弃数据包来控制接收流量——超过定义限制的所有流量都将被丢弃。这可能会影响终端主机上的 TCP 拥塞控制机制，实际达到的带宽可能低于定义值。egress shaper 会尝试将超过限制的数据包排队，而不是直接丢弃。最终，当输出队列满时也会丢弃数据包；不过，这应能更好地利用定义的吞吐量。

## RSTP

RSTP 配置和监控支持按端口和全局方式进行，可在 RSTP 菜单中使用。

![Swos rstp css326](/img/6e7df850ef26634b.webp)

| 属性 | 说明 |
| --- | --- |
| **Bridge Priority（hex）** | 用于 Root Bridge 选择的 RSTP 网桥优先级 |
| **Port Cost Mode** | 根据链路速度自动检测 RSTP 端口开销有两种方法。<br/><code>short</code>：40G - 1；10G - 2；1G - 4；100M - 10；10M - 100<br/><code>long</code>：40G - 500；10G - 2000；1G - 20000；100M - 200000；10M - 2000000 |
| **Forward Reserved Multicast** | 是否转发位于 <strong>01:80:C2:00:00:0x</strong> 范围内的 IEEE 保留组播 MAC 地址。符合 R/M/STP 标准的交换机不应转发这些数据包。<br/><br/>如果启用该设置，SwOS 将转发保留的组播 MAC 数据包并禁用 RSTP：<br/>- 交换机将不处理传入的 BPDU（Bridge Protocol Data Units）<br/>- 它也不会发送自己的 BPDU<br/>- Bridge Priority 和按端口的 RSTP 配置设置将不再生效。<br/><br/>启用保留 MAC 地址转发可能会影响依赖这些地址的某些协议。建议仅在绝对必要时启用转发，例如透明桥接场景（如延长长链路、将网桥用作媒体转换器或进行网络分析）。<br/><br/>值得注意的 MAC 地址和协议示例（由 RouterOS 使用）：<br/><code>01:80:C2:00:00:00</code> - Spanning Tree Protocol（STP）<br/><code>01:80:C2:00:00:01</code> - Ethernet Flow Control<br/><code>01:80:C2:00:00:02</code> - Link Aggregation Control Protocol（LACP）<br/><code>01:80:C2:00:00:03</code> - Dot1x 客户端和服务器<br/><code>01:80:C2:00:00:08</code> - Spanning Tree Protocol（用于 802.1ad 网桥，使用 <code>ether-type=0x88a8</code>）<br/><code>01:80:C2:00:00:0D</code> - Multiple VLAN Registration Protocol（用于 802.1ad 网桥，使用 <code>ether-type=0x88a8</code>）<br/><code>01:80:C2:00:00:0E</code> - Link Layer Discovery Protocol、Multi-chassis Link Aggregation Group 和 Precision Time Protocol<br/><br/>Flow Control MAC 地址 <code>01:80:C2:00:00:01</code> 是一个例外——SwOS 不会转发它。 |
| **Root Bridge** | 网络中选定 Root Bridge 的优先级和 MAC 地址（只读） |
| **RSTP** | 在该端口上启用或禁用 STP/RSTP 功能 |
| **Mode** | 显示特定端口上的 STP/RSTP 功能模式（只读）：<br/><code>RSTP</code><br/><code>STP</code> |
| **Role** | 显示特定端口角色（只读）：<br/><code>root</code> - 面向 root bridge 的端口，将用于向 root bridge 转发流量或从 root bridge 转发流量<br/><code>alternate</code> - 面向 root bridge 的端口，但不会转发流量（root 端口的备份）<br/><code>backup</code> - 背向 root bridge 的端口，但不会转发流量（非 root 端口的备份）<br/><code>designated</code> - 背向 root bridge 的端口，并将转发流量<br/><code>disabled</code> - 不严格属于 STP 的端口（RSTP 功能已禁用） |
| **Root Path Cost** | 显示面向 root bridge 的端口的根路径开销（只读） |
| **Type** | <code>edge</code> - 不应接收任何 BPDU 的端口，应连接到终端站（只读）<br/><code>point-to-point</code> - 工作在全双工链路上的端口，可以成为 STP 的一部分并处于转发状态（只读） |
| **State** | 显示每个端口状态（只读）：<br/><code>forwarding</code> - 端口参与流量转发并学习 MAC 地址，正在接收 BPDU<br/><code>discarding</code> - 端口不参与流量转发且不学习 MAC 地址，正在接收 BPDU<br/><code>learning</code> - 端口不参与流量转发但正在学习 MAC 地址 |

## VLAN 和 VLANs {#vlan-and-vlans}

交换机端口的 VLAN 配置。

![Swos vlan css610](/img/3441762ea56c20d5.webp)

| 属性 | 说明 |
| --- | --- |
| **VLAN Mode** (*disabled \| optional \| strict*；默认：**optional**) | VLAN 过滤模式；这些选项与 egress 端口相关（strict 模式除外）。<br/><code>disabled</code> - 不使用 VLAN 表。交换机会丢弃 egress 端口上带 VLAN 标签的数据包。如果数据包带有 VLAN 标签，并且 VLAN ID 与 egress 端口上的 <code>Default VLAN ID</code> 匹配，则在 <code>VLAN Receive=any</code> 时，交换机会移除 VLAN 标签并转发该数据包。<br/><code>optional</code> - 禁用 VLAN 过滤。将带有 VLAN 表内不存在的 VLAN 标签 ID 的数据包，按与不带 VLAN 标签的数据包相同方式处理。<br/><code>strict</code> - 启用 VLAN 过滤并进行额外的 ingress 过滤，检查 ingress 端口是否为 VLAN 表中所接收 VLAN ID 的成员。ingress 端口上接收到的 VLAN ID 与 VLAN 表不匹配的数据包将被丢弃。必须为 access 端口指定 Default VLAN ID，因为该值将用于为特定端口的 ingress 流量添加标签，并为 egress 流量移除标签。 |
| **VLAN Receive** (*any \| only tagged \| only untagged*；默认：**optional**) | 根据 VLAN 标签是否存在来过滤接收到的流量。<br/><code>any</code> - 允许特定端口上带标签和不带标签的数据包<br/><code>only tagged</code> - 仅允许带 VLAN 标签的数据包。“Default VLAN ID”将不起作用，因为它仅适用于不带标签的流量<br/><code>only untagged</code> - 仅允许不带 VLAN 标签的数据包 |
| **Default VLAN ID** (*integer: 1..4095*；默认：**1**) | 交换机将接收到的不带标签数据包放入“Default VLAN ID”VLAN。仅对不带标签的流量生效，并且仅在 **VLAN Receive** 设置为“any”或“only untagged”时生效。它不适用于带标签的流量。该参数通常用于为 access 端口分配特定 VLAN。当数据包的 VLAN ID 与 Default VLAN ID 匹配时，也用于为 egress 流量移除标签。 |
| **Force VLAN ID** (*yes \| no*；默认：**no**) | 为所有 ingress 流量（带标签和不带标签）分配 `Default VLAN ID` 值。在所有 VLAN Mode 下均生效。如果端口接收到带标签的流量，并且 `Default VLAN ID` 设置为 1，则启用该参数后，egress 流量将不带标签。 |

交换机端口的 VLAN 成员配置。

![Swos vlans css610](/img/bdb180a9a3afc27b.webp)

| 属性 | 说明 |
| --- | --- |
| **VLAN ID** (*integer: 1..4095*；默认：**0**) | 要分配端口的 VLAN ID |
| **IGMP Snooping** (*yes \| no*；默认：**no**) | 在指定 VLAN 上启用或禁用 IGMP Snooping。启用后，交换机会监听来自指定 VLAN 的 IGMP Join 和 Leave 请求，并且仅将流量转发到已从指定 VLAN 发送 IGMP 成员请求的端口。禁用后，交换机会向所有 VLAN 成员端口泛洪组播流量。 |
| **Members** (*ports*；默认：**none**) | 允许在指定 VLAN 上转发流量的端口组 |

## Hosts

此表表示动态学习到的 MAC 地址到端口的映射条目。它可以包含两类条目：动态和静态。动态条目会自动添加——这也称为学习过程：当交换机从某个端口收到数据包时，它会将该数据包的源 MAC 地址以及收到该数据包的端口添加到主机表中，因此当收到具有特定目标 MAC 地址的数据包时，它知道应将数据包转发到哪个端口。如果主机表中不存在目标 MAC 地址，则它会将数据包转发到组中的所有端口。动态条目大约 5 分钟后超时。

如果已存在具有相同 MAC 地址的动态条目，静态条目将接管该动态条目。添加静态条目还可使用更多功能。

![Swos shost css610](/img/d22df8b89cf64db5.webp)

**静态主机属性**

| 属性 | 描述 |
| --- | --- |
| **Ports** | 数据包应转发到的端口 |
| **MAC** | MAC 地址 |

**动态主机属性（只读）**

| 属性 | 描述 |
| --- | --- |
| **Port** | 数据包应转发到的端口 |
| **MAC** | 学习到的 MAC 地址 |

## SNMP

SwOS 支持 SNMP v1 和 v2c（对 GetRequest、GetNextRequest 和 GetBulkRequest 的响应），并使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（仅用于 health、PoE-out 和 SFP 诊断）。不支持 SNMP trap 和写入 SwOS 配置。

可用的 SNMP 数据：

- 系统信息
- 系统运行时间
- 端口状态
- 接口统计信息
- 主机表信息

![Swos snmp2 1](/img/f3b87569bbcad587.webp)

| --- | --- |

| **Community** | SNMP community 名称 |
| **Contact Info** | NMS 的联系信息 |
| **Location** | NMS 的位置信息 |

## ACL 和 ACL Stats 选项卡 {#acl-and-acl-stats-tabs}

访问控制列表（ACL）规则表是一个非常强大的工具，可基于 L2、L3 和 L4 协议报头字段条件，以线速执行数据包过滤、转发和 VLAN 标记。每条规则包含条件部分和动作部分。

![CSS610 ACL table](/img/38f5c04e1dfbc157.webp)

**条件部分参数**

| 属性 | 说明 |
| --- | --- |
| **From** | 数据包进入的端口 |
| **MAC Src** | 源 MAC 地址和掩码 |
| **MAC Dst** | 目的 MAC 地址和掩码 |
| **Ethertype** | 封装在以太网帧载荷中的协议 |
| **VLAN** | VLAN 报头存在状态：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 标签 ID |
| **Priority** | VLAN 标签中的优先级 |
| **IP Src**（IP/netmask:port） | 源 IPv4 地址、网络掩码和 L4 端口号 |
| **IP Dst**（IP/netmask:port） | 目的 IPv4 地址、网络掩码和 L4 端口号 |
| **Protocol** *（integer）* | IP 协议 |
| **DSCP** | IP DSCP 字段 |

**动作部分参数**

| 属性 | 说明 |
| --- | --- |
| **Account as** | 选择用于统计匹配数据包的计数器 |
| **Redirect To** | 强制指定新数据包的目的端口 |
| **Mirror** | 克隆数据包并将其发送到 mirror-target 端口 |
| **Drop** | 丢弃数据包 |
| **Set VLAN ID** | 如果存在 VLAN 标签，则更改 VLAN 标签 ID |
| **Priority** | 如果存在 VLAN 标签，则更改 VLAN 标签优先级位 |
| **DSCP** | 更改 IP DSCP 字段 |

每条 ACL 规则都可以分配到特定计数器，用于统计匹配的数据包。

![Css610 acl stats](/img/034e0e4867cd7c31.webp)

## 重置和重新安装 {#reset-and-reinstall}

CSS610 内置备份 SwOS 固件，可在标准固件损坏或升级失败时加载：

- 设备启动期间按住 Reset 按钮几秒钟，将重置配置并加载备份固件。
- 加载备份固件后，可以使用 Web 浏览器连接到 192.168.88.1（或 DHCP 服务器租用的地址），并安装新的 SwOS 固件。
