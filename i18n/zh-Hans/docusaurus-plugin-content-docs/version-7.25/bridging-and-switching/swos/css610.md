## 概述 {#summary}

SwOS Lite 是一款专为管理 MikroTik CSS610 系列交换机产品而设计的操作系统。CSS610 系列交换机仅支持 SwOS Lite 操作系统。

与 CSS3xx 系列交换机相比，主要区别在于：

- 不支持 Independent VLAN Learning
- 不支持 VLAN 模式 "enabled"
- 不支持 ACL 速率限制
- 支持端口出方向速率限制

---

## CSS610 系列特性 {#css610-series-features}

| 功能 | 描述 |
| --- | --- |
| **Forwarding** | 全非阻塞线速交换Host 表中最多 16k 条 MAC 表项转发数据库仅基于 SVL 工作端口隔离巨型帧支持 - 10218 字节 |
| **生成树协议** | 支持 RSTP |

| **Quality of Service (QoS)** | 入口流量限制；出口流量限制 |
| **Access Control List** | 入口 ACL 表；最多 32 条 ACL 规则（受 SwOS 限制）；基于端口、L2、L3、L4 协议头字段进行分类；ACL 动作包括过滤、转发和修改协议头字段 |

## 连接到交换机 {#connecting-to-the-switch}

打开 Web 浏览器，输入交换机的 IP 地址（默认为 192.168.88.1），随后会出现登录屏幕。交换机也可以运行 DHCP 客户端，请检查 DHCP 服务器是否已分配其他 IP 地址。

![Swos login css610](/img/388461ec86ffddb8.webp)

SwOS 默认 IP 地址：**192.168.88.1**，用户名：**admin**，并且没有密码。

[邻居发现](../../system-information-and-utilities/neighbor-discovery.md) 可用于发现 Mikrotik 交换机的 IP 地址。不支持 LLDP。

## 接口概览 {#interface-overview}

SwOS 界面菜单根据设备型号由多个选项卡组成。SwOS 可能包含的所有菜单为：Link、PoE、SFP、Port Isolation、LAG、Forwarding、RSTP、Stats、Errors、Hist、VLAN、VLANs、Hosts、IGMP、SNMP、ACL、System、Health 与 Upgrade。

SwOS 配置工具中按钮的说明：

- **Append** - 在列表末尾添加新条目
- **Apply All** - 应用当前的配置更改
- **Cut** - 从列表中删除条目
- **Clear** - 重置条目的属性
- **Discard Changes** - 丢弃未保存的配置
- **Insert** - 在列表中添加新条目（放置于当前条目之前）
- **Sort** - 按 VLAN ID 对 VLAN 表排序；按 MAC 地址对主机表排序
- **Change Password** - 更改交换机密码
- **Logout** - 从当前交换机登出
- **Reboot** - 重启交换机
- **Reset Configuration** - 将配置恢复为出厂默认值
- **Choose File** - 浏览以选择升级或备份文件
- **Upgrade** - 使用所选文件升级交换机固件
- **Download & Upgrade** - 自动尝试下载并升级固件，运行 Web 浏览器的 PC 应能访问 Internet
- **Restore Backup** - 使用所选备份文件恢复交换机
- **Save Backup** - 从交换机生成并下载备份文件

> **注意：** 每个 RouterBoard 交换机系列设备都有各自的固件，不能安装在其他系列型号上！

## 端口隔离 {#port-isolation}

Port Isolation 表允许或限制特定端口之间的流量转发。默认情况下，所有可用的交换芯片端口都能与任意其他端口通信 —— 不使用隔离。勾选复选框后，即允许流量从该端口转发到被勾选的端口。以下是一些端口隔离示例。

![SwOS Isolated Groups](/img/284614f24611b0f4.webp)

在某些场景下，你可能需要将一组设备与其他组隔离。在此示例中，**Port1-Port5** 上的设备无法与 **Port6-Port10** 上的设备通信，反之亦然。

![SwOS Private VLAN](/img/606fbb63c2620b62.webp)

在某些场景下，你可能需要将所有流量转发到上行端口，同时让所有其他端口彼此隔离。这种配置称为 **Private VLAN** 配置。交换机会将所有以太网帧仅转发到上行端口 **Port1**，而上行端口可以访问所有其他端口。

![SwO isolation example3](/img/de28135343d9795b.webp)

单独隔离的 **Port1**（例如用于管理目的）—— 它无法向任何其他端口发送流量，也无法从任何其他端口接收流量。

> **注意：** 可以通过勾选其中一个复选框，然后水平拖动（单击并拖动）来勾选/取消勾选多个复选框。

> **注意：** (R)STP 仅在 Private VLAN 配置中才能正常工作。在包含多个隔离交换机组的配置中，(R)STP 可能无法正确接收 BPDU，从而无法检测网络环路。

## LAG {#lag}

支持兼容 IEEE 802.3ad (LACP) 的链路聚合，也支持静态链路聚合，以仅基于二层哈希实现故障切换和负载均衡。最多支持 16 个链路聚合组，每组最多 8 个端口。每个单独的端口都可以配置为 Passive LACP、Active LACP 或 Static LAG 端口。

| 属性 | 描述 |
| --- | --- |
| **模式** *（默认值：passive）* | 指定端口上的 LACP 数据包交换模式或 Static LAG 模式：`Passive` - 将端口置于监听状态，仅当对端端口使用主动 LACP 模式时才使用 LACP`Active` - 优先启动 LACP，无论对端端口模式如何`Static` - 将端口设置为 Static LAG 模式；需要为所有要加入同一静态 LAG 的端口设置相同的 **Group** 设置 |
| **组** | 指定静态 LAG 组 |
| **Trunk** *（只读）* | 表示端口所属的组编号 |
| **Partner** *（只读）* | 表示对端 MAC 地址；仅在端口加入 LACP 时可用 |

## 转发 {#forwarding}

Forwarding 选项卡提供交换机端口之间的高级转发选项、端口锁定、端口镜像、带宽限制和广播风暴控制功能。

![Swos forw css610](/img/41fc3bd40fd23388.webp)

| 属性 | 描述 |
| --- | --- |
| **端口锁定** | `Port Lock` - 启用或禁用该端口上的 MAC 地址学习。启用该选项后，将限制 MAC 地址学习，此时应配置静态 MAC 地址。任何源 MAC 地址未知的接收帧都将被丢弃`Lock On First` - 允许从第一个接收帧中学习源 MAC 地址；该属性应与 `Port Lock` 一起使用。每当接口状态发生变化时，首个 MAC 地址的学习都会被重置 |
| **端口镜像** | `Mirror Ingress` - 进入该端口的流量是否必须复制并转发到镜像目标端口`Mirror Egress` - 离开该端口的流量是否必须复制并转发到镜像目标端口`Mirror To` - 镜像目标端口 |
| **广播风暴控制** | `Storm Rate` - 限制接口发送的广播数据包数量。速率以比特每秒（bps）为单位`Include Unknown Unicast` - 将主机表中无对应条目的单播数据包纳入 `Storm Rate` 限制 |
| **组播泛洪控制** | `Flood Unknown Multicast` - 更改交换机端口上的组播泛洪选项；仅控制出方向流量。启用时，网桥允许将组播数据包泛洪到指定交换机端口；禁用时，则限制组播流量泛洪。该设置影响所有组播流量，包括非 IP、IPv4、IPv6 以及链路本地组播范围（例如 224.0.0.0/24 和 ff02::1） |
| **Bandwidth Limit** | `Ingress Rate` - 限制进入此端口的流量（bps）`Egress Rate` - 限制离开此端口的流量（bps） |

> **注意：** 可以按端口限制入方向/出方向流量。入方向流量使用 policer，出方向流量使用 shaper。入方向 policer 通过丢包来控制接收的流量 —— 所有超过所定义限制的流量都会被丢弃。这可能影响终端主机上的 TCP 拥塞控制机制，实际达到的带宽可能小于所定义的值。出方向 shaper 会尝试将超过限制的数据包排队，而不是丢弃它们。最终，当输出队列满时它也会丢弃数据包；不过，它应能更好地利用所定义的吞吐量。

## RSTP {#rstp}

RSTP 菜单中提供每端口和全局 RSTP 配置与监控。

![Swos rstp css326](/img/6e7df850ef26634b.webp)

| 属性 | 描述 |
| --- | --- |
| **网桥优先级（十六进制）** | 用于根网桥选择的 RSTP 网桥优先级 |
| **端口开销模式** | 有两种方法可根据链路速率自动检测 RSTP 端口开销。`short`: 40G - 1; 10G - 2; 1G - 4; 100M - 10; 10M - 100`long`: 40G - 500; 10G - 2000; 1G - 20000; 100M - 200000; 10M - 2000000 |
| **转发保留组播** | 是否转发 **01:80:C2:00:00:0x** 范围内的 IEEE 保留组播 MAC 地址。符合 R/M/STP 标准的交换机应避免转发这些数据包。如果启用此设置，SwOS 将转发保留组播 MAC 数据包并禁用 RSTP：- 交换机将不处理传入的 BPDU（桥接协议数据单元）- 它也不会发送自己的 BPDU- 网桥优先级和按端口的 RSTP 配置设置将不再有任何效果。启用保留 MAC 地址的转发可能影响依赖这些地址的某些协议。建议仅在绝对必要时才启用转发，例如在透明桥接配置中（例如延长长距离链路、将网桥用作介质转换器或进行网络分析）。值得注意的 MAC 地址和协议示例（RouterOS 使用的）：`01:80:C2:00:00:00` - 生成树协议（STP）`01:80:C2:00:00:01` - 以太网流控`01:80:C2:00:00:02` - 链路聚合控制协议（LACP）`01:80:C2:00:00:03` - Dot1x 客户端和服务器`01:80:C2:00:00:08` - 生成树协议（用于 802.1ad 网桥，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0D` - 多 VLAN 注册协议（用于 802.1ad 网桥，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0E` - 链路层发现协议、多机箱链路聚合组和精确时间协议流控 MAC 地址 `01:80:C2:00:00:01` 是一个例外 —— 它不会被 SwOS 转发。 |
| **根网桥** | 网络中所选根网桥的优先级和 MAC 地址（只读） |
| **RSTP** | 启用或禁用该端口上的 STP/RSTP 功能 |
| **模式** | 显示特定端口上的 STP/RSTP 功能模式（只读）：`RSTP``STP` |
| **角色** | 显示特定端口角色（只读）：`root` - 朝向根网桥并将用于向根网桥转发流量或从根网桥转发流量的端口`alternate` - 朝向根网桥但不转发流量的端口（根端口的备份）`backup` - 背向根网桥但不转发流量的端口（非根端口的备份）`designated` - 背向根网桥并会转发流量的端口`disabled` - 严格来说不属于 STP 的端口（RSTP 功能已禁用） |
| **根路径开销** | 显示朝向根网桥的端口的根路径开销（只读） |
| **类型** | `edge` - 不应接收任何 BPDU 的端口，应连接到终端站点（只读）`point-to-point` - 在全双工链路中工作的端口，可以参与 STP 并处于转发状态（只读） |
| **状态** | 显示每个端口的状态（只读）：`forwarding` - 端口参与流量转发并学习 MAC 地址，正在接收 BPDU`discarding` - 端口不参与流量转发且不学习 MAC 地址，正在接收 BPDU`learning` - 端口不参与流量转发但正在学习 MAC 地址 |

## VLAN 与 VLANs {#vlan-and-vlans}

交换机端口的 VLAN 配置。

![Swos vlan css610](/img/3441762ea56c20d5.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN 模式**（*disabled \| optional \| strict*；默认值：**optional**） | VLAN 过滤模式；这些选项与出方向端口相关（strict 模式除外）。`disabled` - 不使用 VLAN 表。交换机在出方向端口上丢弃带 VLAN 标签的数据包。如果数据包带有 VLAN 标签且其 VLAN ID 与出方向端口上的 `Default VLAN ID` 匹配，那么在 `VLAN Receive=any` 的情况下，交换机将移除 VLAN 标签并转发该数据包。`optional` - 禁用 VLAN 过滤。对于 VLAN 标签 ID 不在 VLAN 表中的数据包，与不带 VLAN 标签的数据包同等处理。`strict` - 启用 VLAN 过滤，并附加入方向过滤，即检查入方向端口是否为所接收 VLAN ID 在 VLAN 表中的成员。入方向端口上接收到的 VLAN ID 与 VLAN 表不匹配的数据包将被丢弃。必须为接入端口指定 Default VLAN ID，因为它将用于为特定端口的入方向流量打标签、为出方向流量去标签。 |
| **VLAN Receive** (*any \| only tagged \| only untagged*；默认：**optional**) | 基于 VLAN 标签存在情况对接收流量进行过滤。`any` - 允许某个端口上的带标签和无标签数据包`only tagged` - 仅允许带有 VLAN 标签的数据包。"Default VLAN ID" 将不起作用，因为它仅适用于无标签流量`only untagged` - 仅允许不带 VLAN 标签的数据包 |
| **默认 VLAN ID**（*integer: 1..4095*；默认值：**1**） | 交换机将接收到的未打标签数据包放入 "Default VLAN ID" 所指定的 VLAN。仅对不带标签的流量生效，且当 **VLAN Receive** 设置为 "any" 或 "only untagged" 时生效。不适用于带标签的流量。此参数通常用于为接入端口分配特定的 VLAN。如果数据包的 VLAN ID 与 Default VLAN ID 匹配，它也用于为出方向流量去除标签。 |
| **Force VLAN ID** (*yes \| no*；默认：**no**) | 将所有入口流量（带标签和无标签）分配为 `Default VLAN ID` 值。在所有 VLAN 模式下均有效。如果端口接收带标签流量，且 `Default VLAN ID` 设置为 1，则使用此参数后，出口流量将不带标签。 |

交换机端口的 VLAN 成员关系配置。

![Swos vlans css610](/img/bdb180a9a3afc27b.webp)

| 属性 | 描述 |
| --- | --- |
| **VLAN ID**（*integer: 1..4095*；默认值：**0**） | 要为端口分配的 VLAN ID |
| **IGMP Snooping**（*yes \| no*；默认值：**no**） | 在指定 VLAN 上启用或禁用 IGMP Snooping。启用后，交换机将监听来自该 VLAN 的 IGMP Join 和 Leave 请求，并仅向从该 VLAN 发送过 IGMP 成员关系请求的端口转发流量。禁用时，交换机会向所有 VLAN 成员端口泛洪组播流量。 |
| **成员**（*ports*；默认值：**none**） | 允许在指定 VLAN 上转发流量的端口组 |

## 主机 {#hosts}

该表表示动态学习到的 MAC 地址到端口的映射条目。它可以包含两种条目：动态和静态。动态条目会自动添加 —— 这也称为学习过程：当交换机从某个端口接收到数据包时，它会将该数据包的源 MAC 地址以及接收到该数据包的端口添加到主机表中，这样当带有特定目标 MAC 地址的数据包到达时，它就知道应该将数据包转发到哪个端口。如果目标 MAC 地址不在主机表中，则它会将数据包转发到该组中的所有端口。动态条目大约需要 5 分钟超时。

如果已存在具有相同 MAC 地址的动态条目，静态条目将取代动态条目。添加静态条目还可获得更多功能。

![Swos shost css610](/img/d22df8b89cf64db5.webp)

**静态主机属性**

| 属性 | 描述 |
| --- | --- |
| **端口** | 数据包应转发到的端口 |
| **MAC** | MAC 地址 |

**动态主机属性（只读）**

| 属性 | 描述 |
| --- | --- |
| **端口** | 数据包应转发到的端口 |
| **MAC** | 学习到的 MAC 地址 |

## SNMP {#snmp}

SwOS 支持 SNMP v1 和 v2c（对 GetRequest、GetNextRequest 和 GetBulkRequest 的响应），并使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（仅用于 health、PoE-out 和 SFP 诊断）。不支持 SNMP trap 和写入 SwOS 配置。

可用的 SNMP 数据：

- 系统信息
- 系统运行时间
- 端口状态
- 接口统计
- 主机表信息

![Swos snmp2 1](/img/f3b87569bbcad587.webp)

| 属性 | 描述 |
| --- | --- |
| **Enabled** | 启用或禁用 SNMP 服务 |
| **Community** | SNMP 团体名称 |
| **Contact Info** | NMS 的联系信息 |
| **Location** | NMS 的位置信息 |

## ACL 与 ACL Stats 选项卡 {#acl-and-acl-stats-tabs}

访问控制列表（ACL）规则表是一个非常强大的工具，可基于 L2、L3 和 L4 协议头字段条件实现线速的数据包过滤、转发和 VLAN 打标签。每条规则包含条件部分和动作部分。

![CSS610 ACL table](/img/38f5c04e1dfbc157.webp)

**条件部分参数**

| 属性 | 描述 |
| --- | --- |
| **From** | 数据包进入的端口 |
| **MAC Src** | 源 MAC 地址和掩码 |
| **MAC Dst** | 目标 MAC 地址和掩码 |
| **Ethertype** | 封装在以太网帧有效载荷中的协议 |
| **VLAN** | VLAN 头是否存在：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 标签 ID |
| **Priority** | VLAN 标签中的优先级 |
| **IP Src**（IP/netmask:port） | 源 IPv4 地址、子网掩码和 L4 端口号 |
| **IP Dst**（IP/netmask:port） | 目标 IPv4 地址、子网掩码和 L4 端口号 |
| **Protocol** *（integer）* | IP 协议 |
| **DSCP** | IP DSCP 字段 |

**动作部分参数**

| 属性 | 描述 |
| --- | --- |
| **Account as** | 选择用于统计匹配数据包的计数器 |
| **Redirect To** | 强制设置新数据包的目标端口 |
| **Mirror** | 克隆数据包并将其发送到镜像目标端口 |
| **Drop** | 丢弃数据包 |
| **Set VLAN ID** | 如果存在 VLAN 标签，则更改 VLAN 标签 ID |
| **Priority** | 如果存在 VLAN 标签，则更改 VLAN 标签优先级位 |
| **DSCP** | 更改 IP DSCP 字段 |

每条 ACL 规则都可以分配到特定的计数器，匹配的数据包将在其中被统计。

![Css610 acl stats](/img/034e0e4867cd7c31.webp)

## 重置与重新安装 {#reset-and-reinstall}

CSS610 内置备份 SwOS 固件，可在标准固件损坏或升级失败时加载：

- 在设备启动时按住 Reset 按钮几秒钟将重置配置并加载备份固件。
- 加载备份固件后，可以使用 Web 浏览器连接到 192.168.88.1（或从 DHCP 服务器租用的地址）并安装新的 SwOS 固件。
