## 许可基础 {#licensing-basics}

对于 x86 系统（基于 PC 的安装），必须获取许可证密钥。每个系统都有一个唯一标识符，称为 **Software ID**，用于许可目的。

许可证密钥以字符块形式提供。可以从 MikroTik 账户或购买后收到的电子邮件中复制该密钥，然后粘贴到路由器中。可以将密钥直接粘贴到终端中，也可以使用 WinBox License 菜单中的 **Paste Key** 选项。需要重启才能使许可证生效。

:::info
**x86 Software ID** 绑定到存储设备（例如 NAND、SSD、HDD、NVMe）的 MBR。
:::

购买许可证之前，请确认 Software ID 在重启后保持不变。

:::danger
如果底层存储或配置不稳定，Software ID 可能会变化。例如，以下情况可能导致该问题：

- 使用有缺陷或即将失效的存储设备（SSD、HDD、NVMe）。
- RAID 配置设置不正确或无法持久保存。
- 不同启动之间使用不同的存储控制器或适配器。
:::

### 系统要求 {#system-requirements}

- **Package version：** RouterOS v6.34 或更高版本。
- **Host CPU：** x86-64 架构（64 位）。
- **RAM：** 512 MB 或更多。
- **Disk：** 128 MB 或更多。
- **RouterOS v6：** 支持的最大硬盘容量为 16 GB。
- **RouterOS v7：** 最大 RAM 和磁盘空间受 Linux kernel 5.6.3 限制，并取决于具体硬件。

最低 RAM 要求取决于接口数量和 CPU 数量。使用以下公式计算近似值：

- **RouterOS v6：** `RAM = 128 + [ 8 × (CPU_COUNT) × (INTERFACE_COUNT - 1) ]`
- **RouterOS v7：** `RAM = 512 + [ 8 × (CPU_COUNT) × (INTERFACE_COUNT - 1) ]`

## RouterOS 许可证密钥级别 {#routeros-license-key-levels}

可以从 [`/system/license`](/docs/cli-reference/system/license) 菜单获取许可信息：

```text
[admin@MikroTik] > /system/license/print
    software-id: "ABCD-1234"
         nlevel: 6
       features:
[admin@MikroTik] >
```

也可以通过相应的 [WinBox](/docs/management-tools/winbox) 或 [WebFig](/docs/management-tools/webfig) 菜单查看。

安装 x86 系统后，RouterOS 以 **Trial mode** 运行，没有任何限制。你有 24 小时注册 **Level 1 (Free Demo)** 许可证，或购买 Level 4、5 或 6 许可证并应用有效密钥。

```text
[admin@MikroTik] /system/license/print 
  software-id: TRPC-YYR2
   expires-in: 23h48m24s
```

各许可证级别之间的差异如下表所示：

<WideTable>

| **级别编号** | **0（试用模式）** | **1（免费演示）** | **4（WISP）** | **5（WISP）** | **6（Controller）** |
| :-- | :-- | :-- | :-- | :-- | :-- |
| **价格** | [无密钥](https://www.mikrotik.com/download.html) | [免费（需要注册）](https://mikrotik.com/client/) | $45 | $95 | $250 |
| **Wireless4 AP 模式（PtMP）** | 24 小时试用 | - | 是 | 是 | 是 |
| **Wireless6 AP 模式** | - | - | 是 | 是 | 是 |
| **PPPoE 隧道** | 24 小时试用 | 1 | 200 | 500 | 无限制 |
| **PPTP 隧道** | 24 小时试用 | 1 | 200 | 500 | 无限制 |
| **L2TP 隧道** | 24 小时试用 | 1 | 200 | 500 | 无限制 |
| **OVPN 隧道** | 24 小时试用 | 1 | 200 | 无限制 | 无限制 |
| **HotSpot 活跃用户** | 24 小时试用 | 1 | 200 | 500 | 无限制 |

</WideTable>

:::info
如果某项功能未列出，则不受许可证限制。
:::

:::warning
演示许可证将路由器限制为单个接口。该限制适用于多种接口类型（veth、vlan、vxlan 等），不仅限于表中列出的类型。
:::

:::note
Level 2 是从旧版（2.8 之前）许可证格式过渡而来的许可证。此类许可证已不再提供。现有 Level 2 许可证仍可继续使用，但升级需要购买新许可证。Level 3 许可证仅供无线站点（客户端/CPE）使用。*对于 x86 PC，Level 3 不单独出售。*
:::

### 所有许可证 {#all-licenses}

- 永不过期 —— 正在运行且已获得许可的路由器可以无限期使用。
- 支持无限数量的接口。
- 每个许可证仅对单次安装有效。
- 包含无限次软件升级（例外：demo 许可证从 7.8 版本开始不允许升级 RouterOS 版本）。

### 预付密钥 {#prepaid-key}

Prepaid Key 是一种可为 MikroTik 产品预先购买的许可证类型。它使你可以获取许可证，而无需立即将其分配给特定设备。获取后，可使用 Prepaid Key 升级 CHR 实例，或通过使用目标 Software ID 将其转换为 x86 系统或 RouterBOARD 设备的许可证密钥。

## 如何购买 RouterOS 许可证密钥 {#how-to-purchase-a-routeros-license-key}

1. 前往 [mikrotik.com](https://mikrotik.com) 并登录你的账户。
2. 导航到 **“Purchase a RouterOS License Key”** 部分。
3. 选择所需的许可证 Key Level。
4. 将 Key Type 设置为 **“License key”**。
5. 在 License Key Information 字段中，粘贴设备的 Software ID。
6. 选择部署所需的任意可选 Key Features。
7. 选择 **“Place key in the cart”**。
8. 选择 **“Proceed to checkout”** 以完成购买。

![](/img/8bbe36f9bc0a6d5f.png)

## 检查并完成购买 {#review-and-complete-your-purchase}

仔细检查订单详情，然后使用 **Credit Card**（CC）或 **PayPal** 完成付款。

![](/img/bcf666707f80bd5b.png)

您已购买 RouterOS 许可证密钥。

## 如何将 x86 的预付密钥转换为许可证密钥 {#how-to-convert-a-prepaid-key-to-a-license-key-for-x86}

1. **购买 RouterOS [Prepaid Key](/docs/7.24/getting-started/routeros-licensing/x86#prepaid-key)。**

   - 登录你的 [mikrotik.com](https://mikrotik.com) 账户。
   - 如果尚未购买 RouterOS Prepaid Key，请购买一个。

2. **访问“Make a Key from Prepaid Key”部分。**

   - 在你的账户中导航到“Make a key from prepaid key”部分。

3. **选择并转换 Prepaid Key。**

   - 从列表中选择所需的 Prepaid Key。
   - 输入要授权的 x86 设备的 **Software ID**，或要升级许可证级别的路由器的 **Software ID**。

![](/img/e711992d34ff1204.png)

1. **生成 License Key。**

   - 点击“Generate”。
   - 确认消息出现：“Successfully converted prepaid key to a new license!”。

![](/img/b2441fab5c176c43.png)

1. **应用 License Key。**

   - 复制生成的 license key。
   - 将其粘贴到 x86 设备中以应用许可证。

你已成功将 Prepaid Key 转换为 x86 设备的 license key。

## 替换密钥 {#replacement-key}

Replacement Key 是 MikroTik 支持团队在 x86 存储设备故障或运行 RouterOS 的 x86 实例丢失许可证时签发的特殊许可证密钥。其费用为 10 美元，每个原始密钥只能签发一次。

在签发 Replacement Key 之前，MikroTik Support 可能要求提供原始磁盘已故障的证明。在某些情况下，这包括将故障磁盘实体寄送至 MikroTik。

## 替换密钥请求 {#replacement-key-request}

1. **登录并提交请求**
   - 登录你在 [mikrotik.com](https://mikrotik.com) 的账户。
   - 使用“[Support Contact Form](https://help.mikrotik.com/servicedesk/servicedesk/)”提交请求，或直接发送电子邮件至 [support@mikrotik.com](mailto:support@mikrotik.com)。
   - 在请求中包含以下信息：
     - **清楚说明为什么需要替换密钥。**
     - **旧 Software ID 以及注册该 ID 的账户。**

2. **等待确认并应用密钥**
   - 当 MikroTik 支持团队确认替换密钥已添加到你的账户后，登录并导航到 **“Make a key from replacement key”** 部分。
   - 继续执行激活操作。

![](/img/d9913b7629d99ed3.png)

1. **Select the License Level**
   - 选择要应用 replacement 的许可证级别。

2. **Enter the New Software ID**
   - 输入目标设备的 **新 Software ID**。

3. **完成购买**
   - 选择 **“Add license replacement to cart”** 进入结账流程并完成付款。

![](/img/1e388024f0024c24.png)

1. **获取密钥**
   - 包含新许可证密钥的确认邮件将发送至你账户注册的电子邮件地址。
   - 新生成的密钥也可在 **“Search and view all keys”** 部分的 **“Purchased YYYY”** 文件夹中找到，其中 **“YYYY”** 表示当前年份。

:::warning
*每个原始密钥只能签发一个替换密钥。同一密钥不能重复使用替换密钥流程。如果需要第二次替换，必须为 RouterOS 设备购买新密钥。*
:::

## 获取和管理许可证 {#obtaining-and-managing-licenses}

### 在哪里可以购买 RouterOS 许可证密钥？ {#where-can-i-buy-a-routeros-license-key}

要为 **x86 PC installation** 购买许可证，必须注册[我们网站上的账户](https://www.mikrotik.com/client)，并使用账户门户中的 [Purchase a RouterOS license key](#how-to-purchase-a-routeros-license-key) 选项。

### 能否升级 x86 许可证级别？ {#can-i-upgrade-the-x86-license-level}

要升级 x86 许可证级别，你必须按全价购买所需的许可证密钥。

### 如果你在其他位置购买了密钥 {#if-you-purchased-your-key-elsewhere}

如果许可证是通过第三方供应商购买的，请直接联系该供应商获取支持，他们负责协助处理其售出的许可证。

### 如果已有许可证并希望将其移至另一个账户 {#if-i-have-a-license-and-want-to-move-it-to-another-account}

应用 x86 许可证密钥后，该密钥会绑定到你的 MikroTik 账户，无法转移到其他账户。唯一可以在账户之间转移的许可证类型是未使用的预付费密钥。作为 Training 礼物收到的预付费密钥不可转移。要转移已购买的预付费密钥，请在 MikroTik Account 的 **ROUTEROS KEYS** 部分中转到 **Transfer prepaid keys**。

### 如果设备上的许可证丢失 {#if-you-have-lost-a-license-on-your-device}

如果因任何原因丢失路由器许可证，请将路由器升级到最新的 RouterOS 版本，并使用 [mikrotik.com](https://mikrotik.com) 账户中的 **“Request license key”** 选项。提交请求时，请使用 RouterOS 中 [`/system/license`](/docs/cli-reference/system/license) 菜单下的 Software ID 和序列号。收到许可证密钥后，将其应用到设备。如果请求功能无法使用，请联系 [support@mikrotik.com](mailto:support@mikrotik.com) 获取帮助。

:::warning
*如果许可证是因非保修授权经销商进行的维修而丢失，则必须按全价购买新的 RouterOS 许可证。*
:::

## 使用许可证 {#using-the-license}

### 可以格式化或重新刷写硬盘吗？ {#can-i-format-or-re-flash-the-drive}

使用非 MikroTik 工具（例如 `dd` 或 `fdisk`）格式化或重新制作存储设备镜像会破坏许可证。

务必格外谨慎，并在尝试此类操作前联系 MikroTik 支持。不建议执行此类操作，更换许可证的请求可能会被拒绝。

要安全重装 RouterOS，请使用 MikroTik 官方工具，例如 **Netinstall**，或通过创建可引导安装介质（例如 USB 闪存盘）从磁盘镜像安装。

### 许可证可以在多少台计算机上使用？ {#how-many-computers-can-i-use-the-license-on}

RouterOS 许可证只能在单个设备/系统上使用。

在 x86 系统上，许可证与 **Software ID** 绑定，而 Software ID 绑定到存储设备（MBR）。因此，可以将同一存储设备移至另一台计算机而不丢失许可证。但是，许可证不能转移到其他存储设备。

格式化或覆盖存储设备会永久清除许可证，需要重新获取。

:::danger
**重要：** 移动或修改存储设备时，请谨慎执行所有操作。使用不同的存储控制器或适配器，或修改 BIOS/UEFI 设置等变更，可能会改变 Software ID 并导致许可证丢失。
:::

按照最佳实践，在进行任何硬件更改前后生成并保存 `supout.rif` 文件。如果 Software ID 发生变化，可以将这些文件提供给 MikroTik support 进行审查。

如果 Software ID 已更改，可以申请替换密钥。

### 我能否将存储设备临时用于 RouterOS 以外的其他用途？ {#can-i-temporarily-use-the-storage-device-for-something-else-other-than-routeros}

No.

### 是否可以将许可证移动到另一个存储设备（例如 SSD、HDD、NVMe）？ {#can-i-move-the-license-to-another-storage-device-for-example-ssd-hdd-nvme}

如果当前存储设备损坏或无法使用，可以通过申请替换密钥将许可证转移到新设备。

更换密钥的价格为 10 美元。

### 我是否必须在路由器中输入完整密钥？ {#must-i-type-the-whole-key-into-the-router}

不需要，只需复制密钥并将其粘贴到 [`/system/license`](/docs/cli-reference/system/license) 菜单的 **Paste Key** 选项中，然后确认重启。

![](/img/152e9782386d7b57.png)

或者，将密钥直接粘贴到 CLI 中，然后按 **Y** 重启。

### 我可以在磁盘上安装其他操作系统，之后再重新安装 RouterOS 吗？ {#can-i-install-another-os-on-my-drive-and-then-reinstall-routeros-later}

不可以。如果使用格式化、分区工具或修改 MBR 的其他工具，将丢失许可证，必须获取新的许可证。此过程不是免费的（请参阅 [Replacement Key](#replacement-key)）。

### 我丢失了 RouterBOARD，可以将许可证转移到其他系统吗？ {#i-lost-my-routerboard---can-i-transfer-the-license-to-another-system}

MikroTik 硬件包含永久绑定到设备的嵌入式许可证。该许可证在任何情况下都不能转移到其他系统。此限制也适用于路由器运行期间应用的任何许可证升级。

### 从经销商处购买的许可证 {#licenses-purchased-from-resellers}

从其他供应商和经销商处购买的密钥不在你的账户中。你的 [mikrotik.com](https://mikrotik.com) 账户仅包含直接从 MikroTik 购买的许可证。

### 我未使用该软件，能否终止我的许可证？ {#i-am-not-using-the-software-can-you-terminate-my-license}

许可证是独立的密钥，MikroTik 无法远程控制你的设备。因此，MikroTik 无法验证许可证是否正在使用。基于此，MikroTik 无法终止任何已签发的许可证。

### 是否可以将 x86 许可证升级或转移到 CHR 许可证？ {#can-i-upgrade-or-transfer-an-x86-license-to-a-chr-license}

不支持将 x86 或 RouterBOARD 许可证升级或转移到 CHR 许可证，反之亦然。必须为 CHR 单独购买许可证。

### 购买密钥时输入了错误的 Software ID 怎么办？ {#what-if-i-entered-the-wrong-software-id-when-purchasing-a-key}

如果许可证密钥是使用错误的 Software ID 生成的（例如，将 `I` 误输入为 `1`），则可以在不联系支持人员的情况下更正密钥中的 Software ID。此功能最多可修正 Software ID 中的 1-2 个字符：

1. 登录你的 [mikrotik.com](https://mikrotik.com) 账户。
2. 导航到 **“Search and view all keys”**。
3. 打开购买年份对应的文件夹 —— **“Purchased YYYY”**，其中 **“YYYY”** 表示当前年份。
4. 选择相关密钥，然后选择 **“Edit”**。
5. 选择 **“Fix Software ID”**。
6. 更正 Software ID 字段中的字符并保存。
