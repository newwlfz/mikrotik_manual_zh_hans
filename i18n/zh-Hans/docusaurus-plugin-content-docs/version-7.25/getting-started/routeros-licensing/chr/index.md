Cloud Hosted Router (CHR) 是 RouterOS 的虚拟化版本，旨在运行于 x86_64 虚拟环境。它提供与 MikroTik 硬件设备相同的核心路由、防火墙、VPN 和管理功能。

本节介绍 CHR 的安装、部署和许可。

说明基于 System ID 的许可、CHR 激活以及虚拟环境的许可选项。
