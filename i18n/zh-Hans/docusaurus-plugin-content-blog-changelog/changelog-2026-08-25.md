2026 年 8 月 25 日文档变更摘要。

## 管理工具 {#management-tools}

- **[SSH](/docs/management-tools/ssh)**、**[Console](/docs/management-tools/console)**、**[Quick Set](/docs/management-tools/quick-set)**、**[RoMON](/docs/management-tools/romon)**、**[FlashFig](/docs/management-tools/flashfig)**、**[WinBox](/docs/management-tools/winbox)**、**[Serial Console](/docs/management-tools/serial-console)** 和 **[WebFig](/docs/management-tools/webfig)**：全面重写了措辞与格式，并将其 CLI 参数表移入 CLI Reference。

## 入门 {#getting-started}

- **[RouterOS 授权](/docs/getting-started/routeros-licensing)**：修正了语法，并补全了 CLI Reference 中的授权参数说明（同时重新调整了 [CHR 授权](/docs/getting-started/routeros-licensing/chr/chr-licensing) 页面的样式）。
- **[备份](/docs/getting-started/configuration-management/backup)**：修正了语法，并将其 CLI 参数移入 CLI Reference。
- **[升级到 v7](/docs/getting-started/upgrading-to-v7)** 和 **[支持输出文件](/docs/getting-started/supout-rif)**：修正了语法，并添加了相关交叉链接。
- **[默认配置](/docs/getting-started/configuration-management/default-configurations)**：改用表格替代项目符号列表重新调整样式，并改进了措辞。
- **[软件规格](/docs/getting-started/software-specifications)**：修正了语法，并添加了相关交叉链接。
- **[网络基础](/docs/getting-started/networking-fundamentals)**：添加了交叉链接，并在 IPv6 邻居发现部分用 Mermaid 图替换了 PNG 示意图。

## 容器 {#containers}

- **[容器应用](/docs/containers/apps)**：大幅重做了 Custom Apps 部分——由 "User-Addable Apps" 更名而来，并将 "How to add apps" 扩展为三种方法——此外当天还修复了若干拼写错误和措辞问题。
