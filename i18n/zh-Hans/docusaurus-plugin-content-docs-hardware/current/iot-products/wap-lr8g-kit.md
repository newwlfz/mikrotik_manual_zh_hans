### [wAP LR8G kit](https://mikrotik.com/product/wap_lr8g_kit) (RBwAPR-2nD&R11e-LR8G) {#wap-lr8g-kit-rbwapr-2ndr11e-lr8g}

wAP 是一款小巧的户外防水设备，内置 LR8 卡，可将 UDP 数据包转发到指定的服务器。

## 快速开始 {#quickstart}

- 确保您的 ISP 允许更换硬件，并会自动分配 IP 地址；
- 打开底部盖板；
- 将外置天线连接到 SMA 接头；
- 将设备连接到电源；
- 将 ISP 线缆连接到以太网端口；
- 在计算机上进入网络连接部分，找到名为 *"MikroTik-..."* 的无线网络。连接该网络（无线密码请查看贴纸）；
- 通过移动应用以无线网络进行配置。也可以通过 **WebFig** 或 **WinBox** 配置工具使用 Web 浏览器 [https://mt.lv/winbox](https://mt.lv/winbox)。下载并打开 **WinBox**，选择 **Neighbors** 选项卡来查找设备；
- 默认 IP 地址为 192.168.88.1。点击该 IP 地址。如果该 IP 不可用，请使用 **WinBox** 并通过 MAC 地址连接。用户名为 "**admin**"，没有密码（或者，某些型号的用户名和无线密码请查看贴纸）；
- 点击 "Check for updates" 按钮，将 RouterOS 更新到最新版本；
- 如需手动更新设备，请访问产品页面 [https://mikrotik.com/products](https://mikrotik.com/products) 查找您的产品。所需的软件包可在 *"Support&Downloads"* 菜单下获取；
- 将下载的软件包上传到 **WebFig** 或 **WinBox** 的 "**Files**" 菜单，然后重启设备；
- 将 RouterOS 软件升级到最新版本，可确保获得最佳性能、稳定性和安全更新；
- 在 *"QuickSet"* 菜单中进行以下设置：选择您所在的国家/地区，以应用该国家/地区的法规设置；
- 在左侧字段中设置无线网络密码；
- 在底部字段中设置路由器密码；
- 在产品标签上找到 *LR Gateway ID*，并将其注册到您的网络服务器中。

## 供电 {#powering}

设备可通过以下方式供电：

- 以太网端口接受无源 PoE 9-28 V DC ⎓。
- 直接输入电源插孔（外径 5.5 毫米、内径 2 毫米，母头，中心针正极插头）接受 9-28 V DC⎓。
- 汽车连接器 12-30 V DC⎓。最大负载下的功耗可达 7 W。

### 连接到 PoE 适配器 {#connecting-to-a-poe-adapter}

- 将设备的以太网线缆连接到 PoE 适配器的 PoE+DATA 端口。
- 将来自本地网络（LAN）的以太网线缆连接到 PoE 适配器。
- 将电源线连接到适配器，然后将电源线插入电源插座。

## 配置 {#configuration}

要为 LR 进行配置，请连接到设备并通过 Web 浏览器登录，或使用移动应用。只需两个简单步骤：**第一步：**

-

登录后，将默认选中 Quick Set，请切换到屏幕右侧的 WebFig。如果通过移动应用进行配置，则点击屏幕右侧的齿轮图标以打开高级菜单。

-

在左侧菜单中，找到并选择 "Lora" 部分。

-

在 newly opened 窗口中，选择 Servers 选项卡。

-

点击 + 添加新的服务器配置。

-

将出现一个新窗口，您需要输入：Name：（服务器名称）Address：（服务器地址）Up port：（通常为 1700）Down port：（通常为 1700）

-

点击 OK 保存。**第二步：**

-

在之前的窗口中选择 Device 选项卡。

-

双击或轻触该行进行配置。

-

在下拉菜单中选择之前输入的网络。

-

点击 Enable 按钮以启用网关。

-

点击 OK 保存。

-

配置完成。有关 LoRa 设置的更多详细信息，请查看此处指南。

使用 The Things Stack 服务器的 UDP 和 LNS 两种场景的配置示例可在此处找到。

我们建议在 QuickSet 菜单中点击 "Check for updates" 按钮，因为将 RouterOS 软件更新到最新版本可确保最佳性能和稳定性。对于无线型号，请确保已选择设备将使用的国家/地区，以符合当地法规。除本文档所述内容外，RouterOS 还包含许多配置选项。我们建议从这里开始熟悉各种可能性：[https://mt.lv/help](https://mt.lv/help) 如果 IP 连接不可用，可使用 WinBox 工具（[https://mt.lv/winbox](https://mt.lv/winbox)）从 LAN 侧通过设备的 MAC 地址进行连接（默认情况下从 Internet 端口的所有访问均被阻止）。出于恢复目的，可以引导设备进行重新安装。

## 按钮和跳线 {#buttons-and-jumpers}

复位按钮有三个功能：

- 在启动过程中按住此按钮，直到 LED 灯开始闪烁，然后松开按钮以复位 RouterOS 配置（共 5 秒）。
- 继续按住 5 秒，LED 变为常亮，此时松开即可开启 CAP 模式。设备现在将寻找 CAPsMAN 服务器（共 10 秒）。
- 或者继续按住按钮 5 秒，直到 LED 熄灭，然后松开，使 RouterBOARD 寻找 Netinstall 服务器（共 15 秒）。无论使用上述哪种方式，如果在设备通电前按下按钮，系统将加载备份的 RouterBOOT 引导程序。这对于 RouterBOOT 调试和恢复很有用。

## 操作系统支持 {#operating-system-support}

设备支持 RouterOS v7 及以上版本。出厂预装的具体版本列于 /system resource 中。其他操作系统未经测试。RouterOS 的 LR 支持仅限于 MikroTik LR 卡，不支持第三方 LoRa 卡。

为避免污染环境，请将设备与生活垃圾分开，并以安全的方式处置，例如送至指定的废弃物处置场所。请了解您所在地区将设备正确运送到指定处置场所的相关程序。
