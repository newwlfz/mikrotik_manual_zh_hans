## 快速开始 {#quickstart}

- 将您的 PC 连接到标有 **MGMT/BOOT** 的端口或第一个以太网端口；
- 将设备连接到电源；
- 将网卡的 IP 设置配置为 192.168.88.2/24；
- 应使用 Web 浏览器中的 **WebFig** 或 **WinBox** 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 进行配置。**提供多种配置方法以确保可访问性；**
- 在 Web 浏览器中打开 192.168.88.1 开始设置。如果该 IP 地址不可用，请使用 **WinBox** 并选择 "**Neighbors**" 标签页来查找设备。然后使用 MAC 地址进行连接。用户名为 "**admin**"，没有密码（或对于某些型号，请在贴纸上查看用户和无线密码）；
- 如需手动更新设备，请访问 mikrotik.com，选择您的型号，并在 "Downloads" 部分找到所需的软件包；
- 将下载的软件包上传到 **WebFig** 或 **WinBox** 的 "**Files**" 菜单，然后重启设备；
- 通过将 RouterOS 软件升级到最新版本，您可以确保最佳的性能、稳定性和安全更新；
- 设置您的路由器密码。

## 供电 {#powering}

本设备通过 IEC C14 标准连接器供电，支持 110/220 V。两个 PSU 用于冗余，每个 100 - 240 V ~1.5 A，50/60 Hz。最大功耗 42 W。

## 扩展插槽和端口 {#extension-slots-and-ports}

- 十二个 10/100/1000 Mbit/s 千兆以太网，支持 Auto-MDI/X；
- 集成内存 2 GB；
- micro-USB AB 型端口；
- RS232 串行控制台端口，串口默认设置为 115200bit/s、8 个数据位、1 个停止位、无奇偶校验。Ether12 端口支持 Etherboot/Netinstall 以重新安装 RouterOS。

## 按钮和跳线 {#buttons-and-jumpers}

**Reset 按钮**：

- 在启动过程中按住此按钮，直到 USER LED 灯开始闪烁，松开按钮即可重置 RouterOS 配置。
- 按住 Reset 按钮并给设备上电（等待 "USER" LED 闪烁后变为稳定 "On"，当 "USER" LED 变为 "Off" 时 - 松开 Reset 按钮）- 设备将以 BOOTP 模式启动，使用 [Netinstall](/docs/getting-started/installation-and-upgrade/netinstall) 重新安装 RouterOS。**MGMT/BOOT 以太网端口用于 Netinstall 过程。** 有关使用 Netinstall 恢复工具的说明，请参阅 RouterOS 文档。

无论使用上述哪种方式，如果在设备上电前按下按钮，系统将加载备份的 RouterBOOT 引导程序。在 LED 开始闪烁之前松开按钮，则仅加载备份 RouterBOOT 而不进行重置。这对于 RouterBOOT 调试和恢复很有用。
