## 首次使用 {#first-use}

- 将您的 PC 连接到标有 **MGMT/ETH/BOOT** 的端口或第一个以太网端口；
- 将设备连接到电源；
- 将网卡的 IP 设置配置为 192.168.88.2/24；
- 配置应通过网页浏览器中的 **WebFig** 或 **WinBox** 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 进行。**提供多种配置方式以确保可访问性；**
- 在网页浏览器中打开 192.168.88.1 开始设置。如果该 IP 地址不可用，请使用 **WinBox** 并选择 "**Neighbors**" 选项卡来查找设备。然后使用 MAC 地址进行连接。用户名为 "**admin**"，没有密码（或者，对于某些型号，请查看贴纸上的用户和无线密码）；
- 如需手动更新设备，请访问 mikrotik.com，选择您的型号，然后在 "Downloads" 部分找到所需的软件包；
- 将下载的软件包上传到 **WebFig** 或 **WinBox** 的 "**Files**" 菜单，然后重启设备；
- 通过将 RouterOS 软件升级到最新版本，您可以确保获得最佳性能、稳定性和安全更新；
- 设置您的路由器密码。

## 供电 {#powering}

本设备可由两个冗余电源供电，每个电源均接受 100-240 V AC 电源。您可以单独使用其中任意一个，也可以同时使用两个。最大功耗为 128 W。

## 安装 {#mounting}

本设备设计用于室内使用，可以使用随附的机架安装件安装在机架机箱中，也可以放置在桌面上。使用十字螺丝刀在设备两侧以及设备背面两侧（如果预定用途是安装在机架机箱中）安装机架安装耳：

- 将支架安装到右前侧。
- 安装右后支架。
- 将支架安装到左前侧。
- 安装左后支架。
- 将长支架安装到机架上，并用螺孔安装设备，使设备安装得顺手合适。
- 如有需要，安装线缆管理支架。

## 配置 {#configuration}

RouterOS 的完整文档可在以下地址获取：[https://mt.lv/help](https://mt.lv/help) 您可以通过网页浏览器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 配置设备。**提供多种配置方式以确保可访问性。** 要开始设置，请在网页浏览器中打开 192.168.88.1 开始配置。如果该 IP 地址不可用，请使用 WinBox 并选择 "Neighbors" 选项卡来查找设备。然后使用 MAC 地址进行连接。用户名为 "admin"，没有密码（或者，对于某些型号，请查看贴纸上的用户和无线密码）。本设备配备一个 RJ45 串口，默认设置为 115200 bit/s、8 个数据位、1 个停止位、无校验位。出于恢复目的，可以从网络重新安装设备，请参见 Reset 按钮。

## 按钮和跳线 {#buttons-and-jumpers}

**Reset 按钮**：

- 在启动期间按住此按钮，直到 USER LED 灯开始闪烁，松开按钮即可重置 RouterOS 配置。
- 按住 Reset 按钮并为设备通电（等待 "USER" LED 闪烁后变为稳定 "On"，当 "USER" LED 变为 "Off" 时松开 Reset 按钮）——设备将以 BOOTP 模式启动，使用 [Netinstall](/docs/getting-started/installation-and-upgrade/netinstall) 重新安装 RouterOS。**MGMT/BOOT 以太网端口用于 Netinstall 过程。** 关于使用 Netinstall 恢复工具的说明，请参阅 RouterOS 文档。

无论使用上述哪种方式，如果在设备通电之前按下按钮，系统都将加载备份 RouterBOOT 引导程序。请在 LED 开始闪烁之前松开按钮，以便只加载备份 RouterBOOT 而不进行重置。这对于 RouterBOOT 调试和恢复非常有用。

Mode 按钮默认不起作用，但可以在 /system routerboard mode-button 菜单中为其指定任意脚本。

## LED {#leds}

本设备有四个 LED 灯。PWR1/2 指示当前使用的是哪个电源。FAULT 指示散热风扇出现问题。USER 可以通过软件进行配置。
