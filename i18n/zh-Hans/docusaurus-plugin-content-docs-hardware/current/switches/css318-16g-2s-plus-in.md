## 快速开始 {#quickstart}

- 从 [https://mikrotik.com/download](https://mikrotik.com/download) 下载最新版本的 SwitchOS 软件；
- 将您的计算机连接到其中一个以太网端口；
- 将设备连接到电源；
- 将计算机的 IP 地址设置为 192.168.88.2；
- 打开 Web 浏览器，默认的管理 IP 地址为 192.168.88.1，用户名为 **admin**，无密码（某些型号的用户名和无线密码请查看标签）；
- 在 Upgrade 选项卡中通过 Web 浏览器上传文件，升级完成后设备将重启；
- 设置您的密码以保护设备安全。

## 配置 {#configuration}

使用 WinBox 实用程序并点击 Neighbors 列表即可发现该设备。默认管理地址为 192.168.88.1。SwOS 是一款专为交换机设计的简单软件。我们建议从本指南开始，以熟悉其功能：[https://mt.lv/help](https://mt.lv/help) 出于恢复目的，可以引导设备以进行重新安装，请参阅相关章节。

## 供电 {#powering}

本设备可通过两路 100-240 V AC ⏦ 输入供电。

本设备在最大负载下的功耗最高为 10 W。带外接设备时最高为 13 W。

## 安装 {#mounting}

本设备设计用于室内，可使用随附的机架安装件安装在机架式机箱中，也可放置在桌面上。如果指定用途为机架式机箱，请使用十字螺丝刀将机架耳固定在设备两侧：

- 将机架耳固定到设备两侧，并拧紧四颗螺丝将其固定到位，如图所示。

![](/img/837a6d2bb5f312fe.webp)

- 将设备放入机架式机箱并对齐孔位，使设备能够方便地装入。
- 拧紧螺丝将其固定到位。本设备没有防水保护，请确保将设备放置在干燥且通风的环境中。*本设备的安装和配置应由具备资质的人员完成。* *我们建议为我们的设备使用 Cat6 网线。*

## 按钮和跳线 {#buttons-and-jumpers}

在启动期间按住此按钮，直到 LED 灯开始闪烁。松开按钮即可重置 SwOS 配置并加载备份软件以进行重新安装和升级。
