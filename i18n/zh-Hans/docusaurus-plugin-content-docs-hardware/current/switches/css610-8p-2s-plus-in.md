## 快速开始 {#quickstart}

- 从 [https://mikrotik.com/download](https://mikrotik.com/download) 下载最新的 SwitchOS 软件版本；
- 将您的计算机连接到任一以太网端口；
- 将设备连接到电源；
- 将计算机的 IP 地址设置为 192.168.88.3；
- 打开 Web 浏览器，默认管理 IP 地址为 192.168.88.1，用户名为 **admin**，无密码（部分型号请查看贴纸上的用户名和无线密码）；
- 通过 Web 浏览器将文件上传到 Upgrade 选项卡，升级后设备将重启；
- 设置您的密码以保护设备。

## 供电 {#powering}

设备可通过电源插孔或交流电源供电。

- 直接输入电源插孔（外径 5.5mm、内径 2mm，母头，中心正极插头）接受 48-57V 直流。
- 交流输入范围 100-240 V。
- 最大功耗（不含附件）12 W。
- 最大功耗 162 W。

## PoE-Out {#poe-out}

- PoE-Out 支持 802.3 af/at 和被动 PoE
- PoE-Out 端口 ether1-ether8：PoE-Out 电压：低电压 28V；
- 高电压 54V（交流输入）或 48-57V（直流输入）
- 低电压 PoE-Out 最大输出电流：1000 mA（每端口）。
- 高电压 PoE-Out 最大输出电流：625 mA（每端口）。
- 总输出功率 140 W。PoE-Out 高电压取决于所用电源：如果使用交流电源，PoE-Out 高电压始终约为 54V；如果使用 DC Jack 电源，PoE-Out 高电压将与 DC Jack 的输入电压一致。PoE-Out 低电压恒定约为 28V。**如果交流电源和直流电源同时使用，PoE-Out 高电压将取决于较高的输入电压。仅当 DC Jack 输入超过 54 伏时才会变化。*

### 连接到 PoE 适配器 {#connecting-to-a-poe-adapter}

- 将设备的以太网线缆连接到 PoE 适配器的 PoE+DATA 端口。
- 将来自本地网络（LAN）的以太网线缆连接到 PoE 适配器。
- 将电源线连接到适配器，然后将电源线插入电源插座。

## LED {#led}

电源将由设备判断并给出相应的电压，如果需求为低电压，LED 将亮绿灯；如果需求为高电压，LED 将亮红灯；当客户端设备无需供电时则不亮。

- 如图所示，将机架挂耳安装到设备两侧，并拧紧四颗螺丝将其固定到位。
