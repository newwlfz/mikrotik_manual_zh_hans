## 快速开始 {#quickstart}

- 将你的 PC 连接到任意以太网端口；
- 将设备连接到电源；
- 将网卡的 IP 设置配置为 192.168.88.2/24；
- 在网页浏览器中使用 WebFig，或使用 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**提供多种配置方式以确保可访问性；**
- 在网页浏览器中打开 [https://192.168.88.1](https://192.168.88.1) 开始设置。如果该 IP 地址不可用，请使用 WinBox 并选择 "Neighbors" 选项卡来查找设备。然后使用 MAC 地址进行连接。用户名为 "admin"，没有密码（或者，对于某些型号，请查看贴纸上的用户和无线密码）；
- 如需手动更新设备，请访问 mikrotik.com，选择你的型号，并在 "Downloads" 部分找到所需的软件包；
- 将下载的软件包上传到 WebFig 或 WinBox 的 "Files" 菜单，然后重启设备；
- 将 RouterOS 软件升级到最新版本，可确保获得最佳性能、稳定性和安全更新；
- 设置路由器密码。

## 供电 {#powering}

本机配备两个 250 W 电源，支持 100-240 V ⏦（~ 50/60 Hz，最大 4.5 A）。无附加负载时的最大功耗为 28 W，在最大负载下可达到 215 W。

## 按钮 {#buttons}

**Reset 按钮**：

- 在启动期间按住此按钮，直到 USER LED 灯开始闪烁，松开按钮即可重置 RouterOS 配置。
- 按住 Reset 按钮并给设备上电（等待 "USER" LED 闪烁后变为稳定的 "On"，当 "USER" LED 变为 "Off" 时——松开 Reset 按钮）——设备会以 BOOTP 模式启动，以便使用 Netinstall 重新安装 RouterOS。**Netinstall 过程使用 MGMT/BOOT 以太网端口。** 有关使用 Netinstall 恢复工具的信息，请参阅 RouterOS 文档。无论使用上述哪种方式，如果在设备上电之前按钮已被按下，系统都将加载备份 RouterBOOT 引导程序。请在 LED 开始闪烁之前松开按钮，以便仅加载备份 RouterBOOT 而不进行重置。这对于 RouterBOOT 调试和恢复很有用。

## LED 指示灯 {#led-indicators}

- 路由器上电时 PWR LED 点亮。
- USER LED 指示设备在启动进入不同模式（例如重置配置或启动设备以使用 Netinstall 工具）时的状态。
- FAULT LED 指示任一散热风扇出现问题。
- 三角形 LED（上排）指示 PoE 输出状态。绿色 LED 表示相应端口使用低电压，红色 LED 表示高电压。单个绿色 LED 闪烁：启动低电压设备时出现问题。单个红色 LED 闪烁：高电压设备出现问题。
- SFP+ 端口绿色 LED 指示各 SFP+ 端口活动状态。
