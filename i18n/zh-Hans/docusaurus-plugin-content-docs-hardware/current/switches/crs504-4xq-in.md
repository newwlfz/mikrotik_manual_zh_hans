## 快速开始 {#quickstart}

- 用您的 PC 连接到任意以太网端口；
- 将设备连接到电源；
- 将网卡的 IP 设置配置为 192.168.88.2/24；
- 在网页浏览器中使用 WebFig，或使用 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**提供多种配置方式以确保可访问性；**
- 在网页浏览器中打开 [https://192.168.88.1](https://192.168.88.1) 开始设置。如果该 IP 地址不可用，请使用 WinBox 并选择 "Neighbors" 选项卡查找设备。继续使用 MAC 地址进行连接。用户名为 "admin"，没有密码（对于某些型号，请查看贴纸上的用户和无线密码）；
- 如需手动更新设备，请访问 mikrotik.com，选择您的型号，并在 "Downloads" 部分找到所需的软件包；
- 将下载的软件包上传到 WebFig 或 WinBox 的 "Files" 菜单，然后重启设备；
- 将 RouterOS 软件升级到最新版本，可确保获得最佳性能、稳定性和安全更新；
- 设置您的路由器密码。

## 安装 {#mounting}

本设备设计用于室内使用，可以使用随附的机架安装配件安装在机架机箱中，也可以放置在桌面上。如果希望放置在平面上，请在路由器底部贴上橡胶脚垫；如果指定用于机架机箱，请使用十字螺丝刀将机架挂耳安装到设备两侧：

- 将机架挂耳安装到设备两侧，并拧紧四颗螺丝将其固定到位，如图所示。
- 将设备放入机架机箱并对齐孔位，使设备能够方便地安装。
- 拧紧螺丝将其固定到位。

## 供电 {#powering}

该设备可通过两个交流输入供电，电压范围为 AC ⏦ 100-240 V。双电源冗余，采用 IEC 电源接口。DC 插孔输入电压 36-57 V DC。2 针端子输入电压 36-57 V DC。PoE in 输入 43-57 V DC。最大负载下的功耗可达 41 W。

## 复位按钮 {#reset-button}

- 要重置配置，请断开设备电源，按住复位按钮，当 USER (USR) LED 开始闪烁时松开。
- 要加载备份引导程序，请在通电前按住复位按钮，三秒后松开。
- 要启动 Netinstall 过程（以 BOOTP 模式启动设备以重新安装 RouterOS），请按住复位按钮，给设备通电，等待 USER (USR) LED 闪烁后变为稳定。当 USR LED 熄灭时，松开复位按钮。无论使用上述哪种方式，如果在设备通电前按下按钮，系统将加载备份 RouterBOOT 引导程序。这对于 RouterBOOT 调试和恢复很有用。
